# Challenge-Admission Governance Protocol

Canonical stage: **MQR-3.137**

## Core laws

- `GENERATOR EXTERIORITY != WORLD-CONTACT ACCESS`
- `WEIRD != IRRELEVANT`
- `WEIRD != WARRANTED`
- `RESOURCE DEFERRED != EPISTEMICALLY REJECTED`
- `LOW INCUMBENT PLAUSIBILITY != ZERO CHALLENGE STANDING`
- `GOVERNANCE VETO != WORLD REFUTATION`
- `OPEN-WORLD STATUS REQUIRES ADMISSION EXTERIORITY, NOT GENERATOR EXTERIORITY ALONE`

## Admission roles

Track separately:

- `GEN` — generate/propose a challenge
- `ADM` — judge epistemic admissibility
- `ALLOC` — allocate scarce execution resources
- `EXEC` — control actual world contact
- `STOP` — terminate an executing probe
- `INTERP` — interpret its receipt
- `CREDIT` — authorize authority gain/loss

Concentrated control across these roles imposes an authority ceiling; full organizational separation is not required.

## Challenge Admission Record (CAR)

For every materially nonroutine challenge record:

- target claim and scope
- generator lineage / CGAG reference
- proposed world-contact route
- prospective adverse consequence, if known
- translation dependence on incumbent vocabulary
- realizability and applicable safety/ethics/legal constraints
- duplication/subsumption relation
- resource estimate
- admission state
- veto/defer reason
- appeal/escalation path
- timing: outcome-blind / post-anomaly / post-failure

## Admission states

- `CA-A ADMIT`
- `CA-B BOUNDED-ADMIT`
- `CA-C DEFER-PRESERVE`
- `CA-D TRANSLATION-ESCALATION`
- `CA-E REJECT-TRACEABLE`
- `CA-F OUT-OF-SCOPE-PRESERVED`

No state silently deletes a scientifically live proposal.

## Relevance-Veto Firewall

A strong irrelevance veto must give a typed reason showing why no current or successor-relevant world-facing consequence can bear on the target. The following are insufficient by themselves:

- low fit to the incumbent model
- unfamiliar variables
- low prior probability under the winner
- disciplinary unfamiliarity
- absence from the current benchmark
- failure to use incumbent terminology

Full translation into the incumbent vocabulary is not required when the challenge tests the adequacy of that vocabulary. A bounded consequence interface is enough for admission review.

## Scarcity rule

Epistemic admissibility and execution priority are separate. A scientifically admissible challenge may be deferred for resources without being reclassified as scientifically irrelevant.

A live programme should preserve some nontrivial path from exterior standing to world contact. Realizers can include pilots, rotating adjudication, instrument-time reserves, external facilities, or partial randomization among proposals that already pass a minimum admissibility floor. No universal quota or mechanism is required.

## Challenge-Admission Governance ladder

- `CAG-0` incumbent veto
- `CAG-1` disclosed screen
- `CAG-2` traceable admission
- `CAG-3` exterior standing
- `CAG-4` protected contact
- `CAG-5` successor-vulnerable admission

`CAG-5` means exterior receipts can actually contract incumbent authority, mutate scope/ontology, and revise the admission rules themselves. It is not a completeness certificate.

## Failure witnesses

- Relevance-Veto Capture (RVC)
- Weird-Probe Suppression (WPS)
- Silent Challenge Extinction
- Admission Escalation Sink
- Safe-Critic Substitution
- Critic/Challenge Monopoly
- Formal Symmetry without Epistemic Symmetry

## Succession

When a challenge defeats the live state:

`FREEZE -> FAIL -> LEARN -> SUCCESSOR -> FRESH RISK`

Do not retroactively relabel post-failure challenge generation as independent confirmation.
