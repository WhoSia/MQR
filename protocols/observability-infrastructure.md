## Lifecycle

`PRESEAL -> OVERLAP -> BRIDGE -> CUTOVER -> MONITOR -> PORTFOLIO EVOLVE -> RETIRE / DORMANT -> TRIGGER / RECALL -> REAUTHORIZE / REVISE / BREAK`

Historical stress tests do not add a fifth constitutional coordinate. They test whether the existing lifecycle yields different, non-vacuous authority trajectories under later-true and later-artifactual anomalies.

## Historical paired-control discipline

For any historical anomaly replay:

1. freeze the contemporaneous information state;
2. separate acquisition, processing, anomaly recognition, validation, publication and public recognition;
3. preserve the observed residual at its native scope;
4. withhold promotion to a world-level cause until the load-bearing measurement graph survives noncommon attack;
5. distinguish probes by which failure modes they cease to share, not by nominal institutional independence;
6. treat later truth as adjudication, never as input to the frozen-time verdict;
7. activate only the constitutional modules materially implicated by the case.

## Negative-control rule: OPERA

The OPERA sequence establishes a reusable failure-localization rule.

- The September 2011 timing residual was a real output of the realized timing chain.
- The November short-bunch rerun removed an important proton-waveform inference rival but retained most of the OPERA timing architecture.
- ICARUS supplied a materially noncommon detector/timing realization and found luminal propagation.
- LVD–OPERA horizontal-muon cross-calibration localized a timing instability through a route independent of the CERN-to-LNGS neutrino time-of-flight inference.
- OPERA identified oscillator and fibre-link effects with opposite signs; therefore a single convenient fault could not be treated as a complete explanation without joint accounting.
- The 2012 multi-experiment campaign and OPERA's upgraded independent timing route converged on luminal propagation.

Therefore same-architecture reproduction increases confidence in the **residual** only to the extent that it breaks a relevant rival. It does not automatically increase authority for the residual's **cause**.

## Failure-Localization Matrix

For a disputed measurement, maintain a **Failure-Localization Matrix (FLM)** recording for each probe:

- which measurement component or inference edge is perturbed;
- which dependencies remain shared;
- which rival classes are actually eliminated;
- whether the probe changes only precision or changes causal localization;
- whether the result is compatible with a world-level effect, apparatus artifact, or both.

`MORE DATA THROUGH THE SAME GRAPH` is not automatically a new defeat route.

## Signed systematic guard

When candidate systematics can move the measured quantity in opposite directions, record direction and plausible magnitude explicitly.

A checklist of considered systematics is insufficient because opposing biases can cancel or mask one another. The authority-bearing object is a signed, jointly evaluated error model tied to interventions where feasible.

## Repair-Confirmation Receipt

A **Repair-Confirmation Receipt (RepCR)** requires, where feasible:

1. identified component or dependency;
2. predicted direction and plausible magnitude of the induced bias;
3. direct intervention, replacement or recalibration;
4. collapse or predicted movement of the disputed effect;
5. materially noncommon replication consistent with the repaired result.

Finding a suspicious component without post-repair convergence is not full failure localization.

## Theory-pressure firewall

External theoretical inconsistency can lower the authority of a broad interpretation and motivate sharper measurement attack. It cannot localize a fibre link, oscillator, baseline error or detector timestamp by itself.

Keep theory-level defeat routes distinct from measurement-system failure localization.

## Positive/negative symmetry

The ozone and OPERA cases receive the same ex ante constitutional form:

`STRUCTURED ANOMALY + LIVE ARCHITECTURE DEBT -> PRESERVE + SCOPE HOLD + DISCRIMINATING PROBE`

They diverge only after noncommon probes return:

- ozone -> world-level anomaly survives and infrastructure interpretation expands;
- OPERA -> timing residual localizes to the measurement system and superluminality loses authority.

This is the intended symmetry. MQR does not predict which anomaly is true; it constrains what kind of probe can legitimately decide.

## Origin rule

**A reproduced anomaly gains world-level authority only to the extent that reproduction breaks the dependence structure capable of reproducing the same artifact.**
