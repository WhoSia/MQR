# Challenge-Opportunity Allocation Protocol

Canonical stage: **MQR-3.138**

## Core laws

- `EQUAL STANDING != EQUAL ALLOCATION`
- `EXPECTED INFORMATION GAIN != EXPECTED AUTHORITY VALUE`
- `PROTECTED EXPLORATION != GUARANTEED FULL-SCALE EXECUTION`
- `EXTERIORITY != PERMANENT RESOURCE ENTITLEMENT`
- `LOW MONETARY COST != LOW EPISTEMIC COST`
- `PORTFOLIO SIZE != OPPORTUNITY DIVERSITY`
- `BROAD AUTHORITY + ZERO LIVE EXTERIOR OPPORTUNITY => REALLOCATION OR AUTHORITY CEILING`

## Challenge Opportunity Profile (COP)

For each admitted challenge track a non-scalar profile:

- `D` — prospective discriminatory bite
- `N` — noncommonness of the failure route
- `C` — direct resource cost
- `K` — contamination / irreversibility cost
- `R` — certification-reserve consumption
- `V` — verifiability / auditability
- `S` — staging potential

Do not collapse COP into a universal scalar score.

## Option-Preserving Allocation

Default when staging is scientifically valid:

`REGISTER -> PILOT -> DISCRIMINATE -> ESCALATE -> REPLICATE/CERTIFY`

A protected challenge receives a real route to world contact, not automatic maximal resources. Pilot-guided escalation does not make pilot and full execution two independent confirmations.

## Authority-Preserving Exploration Floor (APEF)

No fixed exploration quota is constitutionalized. Instead:

> If a broad authority-bearing claim remains live while every materially noncommon admissible challenge has opportunity approaching zero, either restore some exterior challenge opportunity or contract the claim's authority/scope.

## Opportunity states

- `CO-0 REGISTERED`
- `CO-1 PILOT`
- `CO-2 PROTECTED-EXPLORATION`
- `CO-3 ESCALATE`
- `CO-4 CORE-EXECUTION`
- `CO-5 DEFER-PRESERVE`
- `CO-6 STOP-TRACEABLE`

These are resource/opportunity states, not truth states.

## Challenge-Opportunity Ledger (COL)

Record:

- CAR/admission state
- COP dimensions
- ancestry / evidence family
- staging path
- direct and epistemic cost
- current execution opportunity
- prior allocations and receipts
- marginal authority return
- escalation / stop condition
- deferral reason
- reopening trigger

## Failure witnesses

- Incumbent Allocation Capture (IAC)
- Fringe Resource Drain (FRD)
- Selection starvation
- Opportunity-diversity collapse
- Pseudo-precision allocation
- Pilot cycling / challenge subsidy capture
- Certification-reserve burn

## Allocation discipline

- adapt the next probe after each world-contact receipt, but version every adaptive decision;
- discount redundant same-family probes;
- preserve future knowability where possible;
- allow partial randomization only inside a declared admissible tie/near-tie region;
- stop low-yield challenge families traceably when their discriminator collapses;
- permit reopening when new anomalies, instruments, representations, or common-mode failures change their value.

## No universal optimizer

MQR rejects fixed exploration percentages, equal funding, automatic outsider priority, full lotteries, incumbent track-record sovereignty, and `fund every admissible challenge`.

The invariant is narrower: **scarce world contact must preserve some live noncommon defeat options while sequential evidence is allowed to stop low-yield routes and redirect resources.**
