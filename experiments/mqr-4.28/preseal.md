# MQR-4.28 — Truth-Proximity without a Truth Oracle, Verisimilitude Rivalry, Historical Rank-Reversal Attack, Axis-Weight Underdetermination, Scalar-Ablation Test & Whether TPX Measures Earned Realist Proximity rather than Merely Re-encoding the MQR Constitution

Status: ACTIVE / PRESEAL

## Objective
Attack the Real-Language scalar and profile semantics before allowing them to harden into doctrine.

MQR-4.27 introduced:
- C/E/P/R_open authority gates;
- a five-axis profile W/N/I/T/D;
- TPX = geometric mean(W,N,I,T,D).

MQR-4.28 asks whether TPX has any independent claim to truth-proximity, or merely summarizes MQR's own preferred evidential virtues.

## Naming migration
The active language is renamed:

R-Language / R-Packet
->
Real-Language / Real-Packet.

Reason:
avoid collision/confusion with the statistical programming language R and make the intended semantic role explicit.

## Implementation migration
Canonical implementation target:
Rust.

Reference implementation:
Python.

Rationale:
- Rust canonical engine provides explicit enums/types, deterministic parsing, fast execution and a single compiled artifact.
- Python remains a deliberately independent reference implementation for cross-implementation concordance and rapid audit.
- A result counts as compiler-stable only when canonical Rust and independent Python reference outputs agree on the frozen packet corpus.

Implementation language is not an epistemic primitive.
No authority claim may depend on Rust being faster or "safer" in the abstract.

## Literature pressure
Verisimilitude/truthlikeness is an established but contested philosophical programme.

The stage must actively compare TPX against at least:
- Popper-style verisimilitude and its Tichý/Miller failure;
- Niiniluoto similarity/min-sum truthlikeness;
- Schurz/Weingartner relevant-consequence approaches;
- Kuipers truth-approximation / structure-likeness approaches;
- Laudan-style historical challenge to convergent realism.

No literature position is adopted merely by citation.

## Construct-validity problem
A direct historical truth oracle is unavailable.

Therefore TPX may NOT be validated by:
"later theory won, so it was closer to truth at every earlier moment."

That would violate the hindsight firewall.

Validation must distinguish:
A. epistemic warrant available at time t;
B. later successor survival/reinterpretation;
C. truthlikeness relative to an independently specified truth-state/model space.

## Presealed attacks

### A1 — Historical rank-reversal attack
Ask whether a later theory that now has stronger realist standing can receive a lower contemporaneous TPX at introduction than an older mature theory.

If yes:
TPX is not monotonic with retrospective truthlikeness and cannot honestly be called a direct truth-distance measure.

### A2 — Axis-weight underdetermination
Evaluate the same frozen W/N/I/T/D profiles under multiple admissible monotone aggregators:
- geometric mean;
- arithmetic mean;
- harmonic mean;
- minimum;
- weighted geometric means across a broad predeclared weight grid.

If rankings among non-dominating profiles reverse under admissible choices:
no unique scalar ordering is identified without external weight calibration.

### A3 — Pareto/dominance test
If profile A weakly dominates B on every axis and strictly dominates on at least one, A may be ordered above B without arbitrary weights.

If profiles cross:
scalar ordering is presumptively underdetermined unless independent calibration exists.

### A4 — Scalar ablation
Remove TPX entirely while retaining:
- C/E/P/R_open;
- W/N/I/T/D profile;
- Pareto relations;
- rivals;
- residue;
- scope;
- successor shocks.

If all authority promotion/HOLD decisions and successor contractions remain unchanged:
TPX is not constitutive of scientific authority.

### A5 — Re-encoding attack
Test whether the five axes merely restate the MQR constitution.

A coordinate is retained as diagnostically meaningful only if:
- it can vary while gates stay fixed;
- it has a distinct operational receipt;
- removing it loses a distinguishable evidential property.

### A6 — Synthetic oracle sandbox
In controlled toy worlds where the true generating law is known:
- construct claims with known out-of-sample distance/error;
- mechanically derive evidence-process features where possible;
- test whether TPX ordering tracks oracle-defined truth distance.

This sandbox is calibration evidence only.
Synthetic concordance may not be promoted to historical/metaphysical validity.

## Decision rules

### TPX survives as TRUTH-PROXIMITY proxy only if:
1. scalar rankings are reasonably stable under admissible aggregation/weight perturbation;
2. scalar removal loses epistemically relevant ordering not recoverable by profile dominance;
3. historical behavior does not systematically conflict with independently justified truthlikeness judgments;
4. synthetic oracle tests show nontrivial concordance;
5. the mapping from axes to scalar has an independent calibration rationale.

### TPX is demoted if:
it is useful only as a display summary but lacks independent calibration.

### TPX is retired from scientific semantics if:
rank reversals/weight underdetermination are material and scalar ablation preserves all scientific decisions.
