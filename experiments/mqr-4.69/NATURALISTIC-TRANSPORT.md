# MQR-4.69 — Naturalistic Transport

Status: **PARTIAL-NATURALISTIC-ANCESTRY-CONTACT / BASELINE-GOVERNANCE-SUFFICIENT-ON-OBSERVED-DONORS / NO-MQR-SPECIFIC-WORLD-VALIDATION / NO-v0.30-PROMOTION**

## Question

The 4.69 executable Court showed that a provenance-blind present decision surface can be insufficient for future authority transitions, while a compact predictive quotient over history restores sufficiency.

Naturalistic transport asks whether real scientific governance exhibits the same structure:

> Can two presently similar or extensionally matching scientific rules receive different future audit/reopening/continuation treatment because of how they were authorized, generated, challenged, or revised?

The burden is stronger than “provenance is useful.”

## Donor A — Adaptive clinical-trial authorization path

FDA final guidance on adaptive design (2019) defines adaptive designs around **prospectively planned** modifications and treats prospective planning as part of preserving trial integrity and validity.

FDA's medical-device adaptive-design guidance is even more explicit: modifications should generally be prospectively planned and described in the protocol before the study begins; some after-start changes may remain scientifically valid only under restricted conditions, including lack of treatment-outcome knowledge.

This supplies real governance contact for:

~~~text
SAME / SIMILAR CURRENT NUMERICAL ADAPTATION RULE
+
DIFFERENT AUTHORIZATION ANCESTRY
->
DIFFERENT SCIENTIFIC VALIDITY / GOVERNANCE STATUS POSSIBLE
~~~

But this does **not** establish an MQR-specific ancestry ontology.

The ordinary baseline is already strong:

**PRESPECIFICATION / ADAPTIVE-DESIGN GOVERNANCE**

A present state enriched with protocol authorization status can absorb the distinction.

### Current ICH status

ICH E20 on Adaptive Designs for Clinical Trials reached Step 2b draft/public-consultation status in 2025. It should therefore be used only as current comparator pressure, not as a final harmonised standard.

## Donor B — Scientific workflow provenance

Workflow Run RO-Crate (Leo et al., 2024) represents execution provenance for computational workflows and motivates provenance by traceability, reproducibility, accountability, and quality assessment.

The model records inputs, outputs, code, workflow execution and associated objects, and aligns with W3C PROV.

This supplies real contact for:

~~~text
SAME / SIMILAR COMPUTATIONAL OUTPUT
!=
SAME AUDITABILITY OR REPRODUCIBILITY STATUS
~~~

when production lineages differ.

Again this is a strong donor but also a strong novelty kill:

**SCIENTIFIC-WORKFLOW PROVENANCE ALREADY MODELS THIS STATE AUGMENTATION.**

No MQR-specific primitive is earned.

## Donor C — Independent replication

Large-scale replication work continues to describe replication as independent evidence for previous claims.

This supports the distinction between:
- repeated or derivative evidence;
- genuinely independent corroborative evidence.

It is consistent with MQR's provenance-root/common-mode axis.

However it does not by itself provide an exact naturalistic pair with identical present decision surfaces and prospectively observed divergent future authority transitions.

Therefore its role is:

**PROVENANCE-INDEPENDENCE CONTACT / NOT A 4.69 PROSPECTIVE PAIR PROOF.**

## Cross-donor reconstruction

The three donors jointly support:

1. authorization history can affect what adaptation is scientifically licensed;
2. execution provenance can affect auditability/reproducibility despite similar outputs;
3. evidence independence is not reducible to raw result count.

But all three are naturally reconstructed by established state augmentation:

- protocol / prespecification state;
- workflow provenance state;
- evidence-dependence / replication state.

The naturalistic evidence therefore agrees with the executable 4.69 result:

~~~

## Scientific consequence

The real-world evidence does not rescue the four-axis historical ontology.

It instead supports a narrower principle:

> Scientific governance often needs history-derived state beyond the present output/rule surface, but the appropriate retained history is task- and intervention-relative and is frequently already captured by established prespecification, provenance, replication, or revision machinery.

That principle is compatible with the causal-state / predictive-state reconstruction and does not yet require a new MQR-specific ontology.
