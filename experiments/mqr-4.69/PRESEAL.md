## Explanandum lock

4.69 does **not** ask whether scientific history matters in an ordinary narrative sense.

It asks:

> Can two scientific rule-states that are extensionally identical now — same current decision function, same current thresholds, same current admissible actions, same current verdicts, same declared scope — nevertheless differ under a prospectively frozen future audit/reopening intervention solely because their evidence ancestry, authorization path, defeater exposure, or revision lineage differs?

The stage is defeated if the apparent difference can be explained by a present-state variable that was merely omitted from the extensional state definition and can be added without remainder.

The stronger target is therefore:

> What is the minimal state augmentation required to recover future scientific-authority dynamics, and does that augmentation reduce to an ordinary sufficient statistic / belief state / provenance-enriched decision state?

## Core paired-world object

A pair is:

`P = (S_A, H_A, S_B, H_B, U)`

where:

- `S_A, S_B` are present scientific rule states;
- `H_A, H_B` are their warrant/evidence/authorization histories;
- `U` is a prospectively frozen audit or reopening intervention.

A pair qualifies only if, before `U`:

```text
CURRENT_RULE_A = CURRENT_RULE_B
CURRENT_DECISION_SURFACE_A = CURRENT_DECISION_SURFACE_B
CURRENT_THRESHOLDS_A = CURRENT_THRESHOLDS_B
CURRENT_SCOPE_A = CURRENT_SCOPE_B
CURRENT_ACTION_SET_A = CURRENT_ACTION_SET_B
CURRENT_VERDICT_A = CURRENT_VERDICT_B
CURRENT_DECLARED_LOSS_CONTRACT_A = CURRENT_DECLARED_LOSS_CONTRACT_B
```

The only permitted pre-intervention asymmetries are historical/ancestral.

## Prospective interventions

Every qualifying pair must be tested by at least one frozen intervention from this grammar:

- **AUDIT_SOURCE** — inspect evidence or analysis ancestry;
- **REOPEN_WITH_HELD_OUT_DEFEATER** — expose a previously unresolved challenge;
- **REPRODUCE_UNDER_INDEPENDENT_ANCESTRY** — demand an independent lineage;
- **AUTHORIZATION_CHECK** — inspect whether the current rule was prospectively licensed;
- **REVISION_REPLAY** — replay the rule under the pre-change information set;
- **SCOPE_EXPANSION** — move to a declared successor scope without changing the current local rule;
- **WITHDRAW_ANCESTRY_SUPPORT** — remove one provenance root/common-mode support source;
- **COUNTERFACTUAL_RECONSTITUTION** — reconstruct what rule would remain if a historical warrant node were absent.

Interventions must be frozen before outcome reveal.

## Present-state quotient

Define the provenance-blind extensional projection:

`E(S,H) = current extensional scientific state`.

At minimum `E` contains:
- current decision function;
- current threshold/constraint surface;
- current action set;
- current verdict;
- current scope/horizon declaration;
- current typed loss contract;
- current live rival labels visible at the present surface.

Histories are quotiented by:

`(S_A,H_A) ~_E (S_B,H_B) iff E(S_A,H_A)=E(S_B,H_B)`.

4.69 tests whether future authority dynamics descend to this quotient.

## Provenance-blind Markov sufficiency attack

For frozen intervention `U), let:

`T_U(S,H)`

be the post-intervention scientific-authority state.

If there exist qualified paired worlds such that:

`E_A = E_B`

but

`T_U(S_A,H_A) != T_U(S_B,H_B)`,

then `E` is not sufficient for that intervention family.

This earns only:

**EXTENSIONAL_STATE_INSUFFICIENT_FOR_FROZEN_INTERVENTION_FAMILY**.

It does **not** earn:
- universal non-Markovianity;
- irreducible history dependence;
- a metaphysical claim that history cannot be state;
- a proof that full ancestry must be retained.

## State-augmentation / Markovization baseline

4.69 explicitly assumes a strong baseline:

> Any path dependence may in principle be made Markov by augmenting the state with enough history.

Therefore a pairwise separation is only the first step.

The Court must search for an augmented state:

`Z = phi(S,H)`

such that for all tested frozen interventions:

`T_U(S,H) = G_U(Z)`.

Candidate augmentations must include, at minimum:

- full history;
- latest authorization status only;
- provenance-root set;
- provenance-root multiplicity/common-mode class;
- defeater-exposure bitset;
- revision-type sequence;
- last material revision only;
- current reason set;
- reason ancestry DAG quotient;
- warrant-lineage certificate;
- belief/posterior-like sufficient state where definable.

If a small established state representation recovers all tested transitions, the MQR ancestry claim is narrowed accordingly.

## Nonfungibility criterion

Warrant ancestry is **nonfungible on the tested surface** only if:

1. present extensional states are exactly paired;
2. a prospective frozen intervention separates them;
3. the separator depends on ancestry rather than an unpaired present variable;
4. replacing one ancestry with another while holding present extension fixed changes the post-intervention authority state;
5. the separation survives at least one baseline state-augmentation attempt;
6. the needed historical feature is not merely a renamed current authorization bit or current live constraint.

This is still local/finite.

## Causal ancestry intervention requirement

At least one executable pair family must permit an explicit intervention on history representation while holding present extension fixed.

Examples:

- swap provenance DAGs while preserving current rule;
- erase one authorization receipt while preserving current decision surface;
- merge two evidence roots into one common-mode root;
- replace prospective authorization with retrospective ratification while preserving current threshold;
- remove a historical defeater encounter while preserving current verdict.

If the post-audit authority state changes, this is a stronger witness than passive correlation.

## Anti-storytelling guard

The following do not count as evidence for ancestry nonfungibility:

- “one history feels more trustworthy”;
- prestige or institutional reputation;
- mere age of a rule;
- chronology without a typed downstream consequence;
- duplicated narrative detail;
- a different present confidence score;
- a different present action set;
- a hidden present veto not included in the pairing surface;
- retrospective reconstruction chosen after seeing the separating intervention.

## Frozen falsifiers

- **F1 — Present-variable leakage:** pair differs in a present extensional variable.
- **F2 — Markov augmentation absorption:** a compact present augmented state fully recovers transitions.
- **F3 — Full-history triviality:** only storing the entire path works, with no scientifically meaningful compression.
- **F4 — Posterior/belief-state absorption:** a standard belief state captures all relevant ancestry effects.
- **F5 — Provenance-baseline absorption:** ordinary provenance DAG semantics fully explain the distinction.
- **F6 — Prespecification-governance absorption:** authorization ancestry reduces to standard trial/design governance.
- **F7 — Revision-theory absorption:** reason/revision ancestry reduces to established belief/preference revision.
- **F8 — Intervention leakage:** intervention reveals a present difference rather than a historical one.
- **F9 — Hindsight pair construction:** pair was matched after seeing the separating outcome.
- **F10 — No causal swap:** ancestry labels correlate with outcomes but swapping ancestry under fixed present extension does not change the authority transition.
- **F11 — Historical overretention:** a smaller quotient than the proposed certificate preserves every tested transition.
- **F12 — Naturalistic absence:** no real scientific governance case supports ancestry-sensitive continuation rights beyond synthetic semantics.

A negative result is admissible.

### C. Defeater-exposure pair
Same current verdict.
One survived a frozen defeater; the other never encountered it.
Intervention: REOPEN_WITH_HELD_OUT_DEFEATER.

### D. Reason-mutation pair
Same current rule and decision surface.
One arrived by stable reason continuity; one by reason mutation/reversal.
Intervention: REVISION_REPLAY or COUNTERFACTUAL_RECONSTITUTION.

### E. Null-history control
Different histories that should remain scientifically fungible under all frozen interventions.
Required to prevent history inflation.

### F. Baseline-win control
A pair whose apparent ancestry effect is fully captured by a compact ordinary state variable.
Required to prevent MQR from winning by construction.
