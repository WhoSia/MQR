# MQR-4.30 — External Calibration Literature & Kuipers Lineage Audit

## Kuipers is a lineage, not a static doctrine

The current Drive corpus now contains:
- Kuipers (2005), author's synopsis of the 2000 monograph;
- Kuipers (2009), probabilistic extension;
- Kuipers (2011), evidence-guided AGM belief revision;
- Kuipers (2014), empirical progress and nomic truth approximation revisited;
- Kuipers (2016), models/postulates and generalized two-sided theories;
- Kuipers (2020; online 2018), refined model/postulate revision.

The 2014 paper explicitly states that the strong/maximal-theory assumption had been wrongly assumed necessary for roughly 1982–2012.

The 2016 paper makes the correction structural:
theories are two-sided <M,P> objects whose model side claims representability/inclusion and whose postulate side claims exclusion.

The 2020 paper describes this two-sided move as a far-reaching generalization of pre-2012 work and adds structurelikeness, idealization and concretization.

Therefore MQR must not cite "Kuipers" as if 2000 and 2020 instantiate one unchanged theory.

Canonical use:
- 2000/2005 = historical architecture;
- 2014 = explicit assumption correction;
- 2016 = two-sided successor constitution;
- 2020 = refined successor;
- 2009/2011 = probabilistic/dynamic side branches.

This lineage itself supports a core MQR rule:
framework transport across a researcher's own revisions is an empirical/interpretive question, not an identity presumption.

## N literature lane

N=MID, not automatically HIGH.

Replication count does not constitute independent lineage.

This passes the anti-counting test but is one broad cognitive-science domain only.

Therefore:
N external cross-domain calibration = HOLD.
