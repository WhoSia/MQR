# MQR-4.64 — Binding Characterization Manifest

Status: **FROZEN BEFORE LITERATURE NOVELTY-KILL AND EXECUTABLE REVEAL**

## Study families

At least the following structural families must be tested:

1. **Slack constraint world** — typed coordinate exists, but all competent baseline actions already satisfy the constraint.
2. **Binding scarce-separator world** — one or more actions irreversibly destroy a unique future discriminator.
3. **Substitutable-separator world** — apparent unique separator has an alternative route; preservation constraint should release.
4. **Reopening-floor world** — local closure can later be defeated only if a reopenable route survives.
5. **Baseline-absorbed world** — a strong constrained/sequential baseline independently preserves the same reachability.
6. **Oracle-trap world** — constraint would help only if future hidden rival identity is known; must be rejected.
7. **Overconstraint world** — preservation/reopening floor blocks materially superior current action without real future capability gain.
8. **Ancestry-binding world** — nominal evidence multiplicity shares common cause; ancestry constraint changes feasible acquisition only when independent route actually exists.
9. **Debt-binding world** — repeated locally rational actions can eliminate all remaining separators unless a debt/coverage constraint activates.
10. **Reversible control world** — no irreversible capability loss; OPR/ARR-style constraints should release.

## Frozen baseline-equivalence criteria

Two policies/constraints are behaviorally equivalent on a frozen world support if all hold:
- selected-action disagreement rate <= 0.05;
- future reachable-separator-set Jaccard >= 0.95;
- reopening-route-set Jaccard >= 0.95 where applicable;
- terminal declared scientific-success difference <= 0.03;
- irreversible-option-loss difference <= 0.03 normalized range.

Equivalence is local to world support/horizon.

## Constraint activation ledger

For every state/policy/constraint:
- baseline action set;
- constraint-eligible action set;
- removed actions;
- chosen action baseline;
- chosen action constrained;
- live rivals;
- reachable separators before/after;
- reopening routes before/after;
- ancestry classes;
- irreversible losses;
- debt state;
- contemporaneously observable activation variables;
- hidden/oracular variables used = MUST BE NONE.

## Frozen ablations

For each typed constraint that is implemented:
- full baseline + typed constraint;
- baseline without typed constraint;
- baseline with weakest local surrogate;
- baseline with matched conventional constrained-planning analogue when available.

No MQR constraint may be tuned using post-reveal outcomes.

## Promotion gate

A typed diagnostic may be promoted to action constraint only if:
- at least one minimal binding witness exists;
- the witness is non-oracular;
- own-ablation changes reachable scientific capability;
- a strong matched baseline does not already absorb the restriction;
- the constraint releases in slack/reversible/substitutable controls;
- overconstraint rate is reported, not hidden;
- the resulting authority is explicitly local unless the same structural binding condition transports.

## Release / retirement gate

A constraint should be released/retired when:
- its activation set is empty on the eligible support;
- its behavior is baseline-absorbed;
- its witness requires oracle information;
- alternative separators make its claimed unique capability nonunique;
- it overconstrains more often than it preserves the declared capability under the frozen contract.

No scalar MQR score is permitted.
