## Frozen countermodels

1. **Myopic information trap** — highest immediate information gain destroys the only future separator.
2. **Option-preserving low-yield probe** — lower immediate gain preserves a unique later intervention route.
3. **Destructive identifiability gain** — action identifies one parameter while irreversibly destroying discrimination among two live mechanisms.
4. **Prior-sensitive query reversal** — two actions reverse order under admissible prior changes.
5. **Model-class-sensitive query reversal** — action ranking flips when an omitted rival is admitted.
6. **Representation-sensitive information gain** — scalar gain changes under a reparameterization that preserves the live scientific distinction.
7. **Policy-induced sampling blind spot** — adaptive policy stops visiting a region where its model is systematically wrong.
8. **Common-mode evidence inflation** — many adaptively chosen observations share one causal/instrumental ancestry.
9. **Greedy confirmation loop** — each locally best action confirms the currently favored model and suppresses challenge generation.
10. **Reopening-reserve necessity** — using all budget on current exploitation leaves no admissible route to reopen after later defeat.
11. **Fixed exploration Goodhart** — a constant exploration quota wastes budget in one regime and starves it in another.
12. **Query-order noncommutativity** — A then B yields a separator; B then A destroys B's interpretability.
13. **Outcome-contingent option loss** — only one branch of an experiment destroys a future route; scalar expected value hides the asymmetric debt.
14. **Cheap-probe debt accumulation** — repeated low-cost probes create unresolved high-impact mechanism debt.
15. **Cost-normalized value reversal** — value/cost ratio selects a cheap proxy while the expensive action uniquely tests the decision-relevant claim.
16. **Identifiability without action relevance** — parameter becomes identifiable but no live claim/use/decision distinction changes.
17. **Action relevance without information gain** — intervention produces low Shannon gain but directly resolves a live causal distinction.
18. **Exploration bonus representation failure** — bonus magnitude changes under arbitrary feature/refinement choices.
19. **Pareto multiplicity** — multiple actions remain non-dominated across identifiability, option, debt and cost axes.
20. **Lexicographic experiment dictatorship** — fixed priority to world contact causes catastrophic option destruction in a case where reversible staging existed.
21. **Reopening-value reversal** — short-horizon choice dominates now; longer horizon favors preserving a challenge route.
22. **Hidden-rival arrival** — previously optimal policy becomes self-undermining after a new rival enters the frontier.
23. **Adaptive stopping blindness** — policy interprets low marginal gain as saturation because its action generator no longer proposes exterior probes.
24. **Intervention-semantic drift** — repeated use changes the system so later interventions no longer have the same meaning.
25. **Measurement contamination loop** — observation itself perturbs the target enough to invalidate subsequent baseline comparisons.
26. **Sequential debt laundering** — debt is repeatedly relabeled across action types and disappears from a scalar objective.
27. **Randomization-not-oracle** — random exploration breaks one blind spot but does not establish adequacy or optimality.
28. **Universal utility failure** — any fixed scalar weighting can be reversed by a case preserving scientific obligations but changing option/debt asymmetry.

## Positive witnesses

2. Reversible low-cost probe followed by targeted intervention strictly preserves more future discriminating capacity.
3. Explicit destructive-intervention contract legitimately forbids an otherwise informative action.
4. Reopening reserve preserves a future challenge route after current local closure.
5. Action sequence A→B beats B→A because only A preserves B's interpretability.
6. A low-information intervention directly resolves a live causal relation.
7. A prior-sensitive ranking is retained as local rather than laundered into universal order.
8. A newly admitted rival triggers policy reopening.
9. Common-mode ancestry collapses nominal evidence multiplicity.
10. Nonmyopic exploration debt is carried forward when short-horizon selection skips a unique separator.
11. Genuine incomparability produces HOLD rather than arbitrary scalar tie-breaking.
12. Randomized exterior probe is admitted as a bounded blind-spot breaker, not an epistemic oracle.
13. Identifiability gain is admitted only when tied to a live claim/use/decision distinction.
14. Outcome-contingent option loss is receipted branchwise rather than averaged away.
