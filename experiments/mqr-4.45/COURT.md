## Refinement result

For an inherited source debt:

```text
A = {q1,q2}
DEBT(A)
A --REFINE--> {A1={q1}, A2={q2}}
```

covering only `A1` does not discharge the source debt. Covering both target carriers, preserving the full declared challenge union, and retaining source-to-target debt traces can preserve it locally.

The historical accounting key remains the **source debt ancestry**, not the number of refined target carriers.

Therefore:

```text
ONE HISTORICAL SOURCE DEBT
-> TWO REFINED TARGET CARRIERS
!= TWO INDEPENDENT HISTORICAL DEBTS
```

The deliberate `TARGET_CARRIER` negative control detects the corresponding double-count failure.

## Merge result

For:

```text
DEBT(A)
DEBT(B)
A+B --MERGE--> M
```

one target carrier does not collapse two inherited source-debt ancestries.

A merge passes the local continuity court only when every relevant debt ancestry remains traceable into the merged carrier.

Therefore:

```text
TWO HISTORICAL SOURCE DEBTS
-> ONE TARGET CARRIER
!= ONE HISTORICAL DEBT
```

Representation compression is not debt discharge.

## Noncommuting revision diamond

The executable diamond holds source/target fixed while the declared direct and composed paths disagree:

```text

\
 \-> B --FULL---> C
```

The resulting rule is:

```text

-> REVISION AUTHORITY REOPENED
```

The direct path is not promoted to an oracle. Disagreement defeats path-independence; it does not establish direct infallibility.
