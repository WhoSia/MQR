## 2. Constitution before quotient

A chart constitution is:

~~~text
C = (T, X, Γ, P, A, M, D, S)
~~~

and induces a contract-indexed equivalence relation:

~~~text
x ~_C y
~~~

The equivalence is licensed only for the target `T`, domain `X`, transformation grammar `Γ`, probes `P`, interventions `A`, morphisms `M`, defeat distinctions `D` and scope/embedding regime `S`.

This blocks a hidden inference:

~~~text
FORMALLY RELATED
=> SCIENTIFICALLY SAME
~~~

unless the relation survives the declared consequence tests.

## 3. Why Γ replaces G_inert

The predecessor notation `G_inert` was useful but too committal.

A genuine global group requires:
- common domain;
- identity;
- closure;
- associativity;
- inverses.

Scientific representation changes are often only locally defined, object-typed, irreversible at the evidential surface, or certified on a restricted context family.

MQR-4.54 therefore uses a typed transformation grammar:
- GROUP;
- GROUPOID;
- PSEUDOGROUP;
- MONOID;
- PARTIAL_FAMILY.

The type is part of the scientific claim.

A local groupoid/pseudogroup-style receipt is not a failed global group receipt. It is a different authority claim.

## 4. Actual symmetry versus certified inertness

The critical distinction is:

~~~text
ACTUAL CONSEQUENCE-PRESERVING TRANSFORMATION
!=
TRANSFORMATION CERTIFIED INERT
UNDER CURRENT P/A/M/D/S
~~~

The first is a property relative to a fully specified consequence structure.
The second is an earned epistemic status relative to finite current world contact.

This prevents an invalid countermodel.

If `g1` and `g2` really are symmetries of one compositionally closed consequence structure, their composition is not expected to become non-symmetric merely because it is composed.

The executable CM2 instead tests:

~~~text

g2 individually certified
composition enters an untested context
composition exposes a material consequence
------------------------------------------
generator-wise certification != grammar closure
~~~

The failure is in **certification coverage**, not group theory.

## 5. Over- and under-quotienting

### Over-quotient

If:

~~~text
x ~_C y
but
A(x) != A(y)
~~~

for a target-relevant admissible intervention `A`, the quotient is too coarse for that contract.

### Under-quotient

If two states differ only by a transformation already certified consequence-preserving, but the chart counts their difference as progress-bearing change, the quotient is too fine.

These are dual constitutional errors:

~~~text
TOO COARSE -> ERASES WORLD DIFFERENCE
TOO FINE   -> MANUFACTURES SCIENTIFIC DIFFERENCE
~~~

No general rule says the scientifically best quotient is maximally coarse or maximally fine.

## 6. Embedding defeats intrinsic inertness

An internal probe family can fail to see a transformation while a larger relational system can distinguish it.

Therefore:

~~~text
INERT@SUBSYSTEM
!=
INERT@COMPOSITE
~~~

unless an embedding receipt transports the result.

This turns scope from metadata into a load-bearing coordinate.

## 7. Morphism admission is constitutional

Suppose charts A and B disagree under an arrow `m : A -> B`.

Deleting `m` can make the remaining atlas commute.

But:

~~~text
COHERENCE AFTER DELETING
A DISSENTING ARROW
!=
EVIDENCE FOR COHERENCE
~~~

unless arrow exclusion has independent warrant.

Morphism admission is therefore part of WCICR rather than an innocent mathematical convenience.

## 8. Constitution plurality

Two constitutions may:
- agree on every current probe;
- both satisfy current admissibility;
- disagree on a fresh intervention.

Before that fresh intervention, MQR does not force a fake total ordering.

The appropriate state can be:

~~~text
C1 = CURRENTLY ADMISSIBLE
C2 = CURRENTLY ADMISSIBLE
C1 ? C2 = MATERIAL DIFFERENCE NOT YET IDENTIFIED
~~~

This is not “anything goes”.

Both constitutions remain exposed to prospective separation.

## 9. Refinement, compression and authority are distinct

Let equivalence kernels be compared on a common domain.

- refinement identifies weakly fewer pairs;
- compression identifies weakly more pairs.

Neither relation is itself an authority ordering.

A finer chart can preserve a newly material distinction.
It can also merely proliferate representational duplicates.

A coarser chart can remove redundancy.
It can also erase interventionally material structure.

Thus:

~~~text
KERNEL ORDER
!=
AUTHORITY ORDER
~~~

Authority transport needs an independent consequence-preservation receipt.
