## Independent candidate objects

### 1. Rival-Separation Obligation (RSO)

Do not begin from an asserted empirical coordinate.

Begin from a live scientific authority requirement:

```text
RSO = a claim-relevant pair/class of rival world states
      that must remain distinguishable for the target claim to retain authority.
```

An RSO is therefore generated by the live rival frontier and claim/query obligations.

It is not asserted to be an ontic dimension.

### 2. World-Contact Separation Hypergraph (WCSH)

Construct a finite relation:

```text
EXTERNAL ROOT r  --separates-->  RSO o
```

A root covers an RSO only when its externally anchored measurement/intervention route is sufficient to discriminate that obligation under the frozen semantics.

Internal derivations may combine or transform root outputs but do not become new external vertices.

### 3. Frontier-Relative Contact Rank (FCR)

For frozen:
- claim family C;
- live rival frontier F;
- query/intervention class Q;
- external root family R;
- separation incidence S;

define:

```text
rho(C,F,Q,R,S)
  = minimum cardinality of a subset B of R
    such that every live RSO induced by (C,F,Q)
    is separated by at least one root in B.
```

If no such B exists:

```text
rho = UNIDENTIFIED / UNCOVERED
```

This is a finite optimization result.

It is **not**:
- world dimensionality;
- number of independent causal variables;
- number of true mechanisms;
- a truth score;
- or an intrinsic property of the target system.

### 4. Minimal Basis Family

Do not return one arbitrary minimizing set.

Return:

```text
B_min = all minimum-cardinality external root sets
        for the frozen WCSH
```

Rank may be unique while the minimizing basis is not.

### 5. Frontier / Instrument receipt

Every rank receipt must carry identities for:
- claim scope;
- live rival frontier;
- query/intervention class;
- external root universe;
- root semantic versions;
- separation incidence;
- freshness state.

The receipt expires/reopens when any load-bearing identity changes.

## Frozen attacks

### Attack 1 — Degree Split Inflation

Take one world-contact obligation D represented as one "degree".

Split it syntactically into D1 and D2 while changing coverage declarations, without changing the actual rival states that need discrimination.

If rank changes merely because the degree vocabulary changed:

```text
DECLARED-DEGREE RANK = REPRESENTATION-DEPENDENT
```

The empirical-degree ontology cannot be primitive.

### Attack 2 — Degree Merge Deflation

Merge two genuinely distinct discrimination obligations into one declared degree.

If a single root is then allowed to "cover the degree" despite failing one of the underlying rival separations, declared-degree minimum falsely decreases.

### Attack 3 — Rival-Separation Reparameterization

Rename, split or merge descriptive coordinates while preserving the actual set of rival-separation obligations and root-to-obligation incidence.

Candidate invariance:

```text
INCIDENCE-ISOMORPHIC WCSHs HAVE THE SAME FCR.
```

This is the target representation-invariance theorem.

### Attack 4 — Root-Set Nonuniqueness

Construct multiple distinct minimum WCBs with the same FCR.

The court must reject:

```text
MINIMUM RANK -> UNIQUE SCIENTIFIC BASIS
```

A rank certificate must expose the basis family or an explicit equivalence class, not silently select one root set as canonical.

### Attack 5 — Anchor Exchangeability / Matroid Smuggling

Test whether minimum WCBs satisfy one-for-one basis exchange.

Frozen counterexample obligation universe:

```text
O = {1,2,3,4}

r1 = {1,2}
r2 = {3,4}

r3 = {1,3}
r4 = {2,4}

B1 = {r1,r2}
B2 = {r3,r4}
```

Both B1 and B2 are minimum covers of size 2.

But replacing r1 in B1 by either r3 or r4 leaves one obligation uncovered.

Therefore arbitrary WCB families need not satisfy the matroid basis-exchange axiom.

Target verdict:

```text
WCB RANK != MATROID RANK IN GENERAL
```

Matroid structure may be imported only as an additional proved property of a particular scientific surface.

### Attack 6 — Instrument-Family Dependence

Hold the target world/rival frontier fixed.

Add a genuinely external measurement root whose observation covers several RSOs jointly.

The minimum number of roots can fall.

Therefore:

```text
FCR DEPENDS ON AVAILABLE EXTERNAL ROOT TECHNOLOGY.
```

It is not an intrinsic dimension of the world.

### Attack 7 — Rival-Frontier Expansion

Hold root semantics fixed and add a new live rival-separation obligation.

Candidate monotonicity:

```text
F subseteq F'
=> rho(F) <= rho(F')
```

when the original root incidence on old obligations is preserved.

This expresses why new rivals can increase required world contact.

### Attack 8 — Query / Intervention Expansion

Expand the load-bearing query/intervention class while holding old obligations and root semantics fixed.

The required RSO set may grow.

Rank must not decrease merely because the claim asks more of the world.

### Attack 9 — Root Drift / Edge Deletion

A previously discriminating root may drift, causing a separation edge to disappear.

Frozen example:

```text
before:
  r1 -> {o1,o2}
  r2 -> {o2}
  rho = 1

after drift:
  r1 -> {o1}
  r2 -> {o2}
  rho = 2
```

A basis certificate must reopen or expand.

Derived receipts cannot preserve old coverage by inertia.

### Attack 10 — Root Improvement / Edge Addition

Calibration or redesigned measurement may add a real separation edge.

FCR may decrease.

Therefore rank evolution is not a universal monotone history of "knowledge dimension"; it is relative to the versioned root semantics.

### Attack 11 — Cost-vs-Cardinality Conflation

Two bases may have equal cardinality but radically different:
- monetary/compute cost;
- adverse intervention cost;
- freshness;
- replication independence;
- failure correlation;
- drift exposure.

Rank is cardinality unless another objective is declared.

Do not silently turn "minimum roots" into "best experiment design".

### Attack 12 — Common-Cause Root Compression

One external root can cover many RSOs while all outputs share one hidden failure mode.

Low FCR may therefore mean efficient coverage, not independent evidence.

MQR-4.30/4.40 common-cause discipline remains live.

### Attack 13 — Open-World Rival Injection

Any finite FCR is relative to the frozen live rival frontier.

Construct a successor rival outside F that is not separated by the minimizing basis.

Target boundary:

```text
FINITE FRONTIER MINIMALITY != FINAL OPEN-WORLD MINIMALITY
```

### Attack 14 — Ontology-from-Optimizer Circularity

The optimizer may minimize only after being told what must be separated.

It cannot infer the complete obligation ontology from the fact that its chosen roots cover the supplied obligations.

Target guard:

```text
OPTIMIZER COMPLETENESS != FRONTIER COMPLETENESS
```

## Candidate replacement of "empirical degree"

MQR-4.41 will attempt to retire **empirical degree** as a primitive world ontology term in the WCB constitution.

Candidate replacement:

```text

= frozen claim-relative set of rival-separation obligations
```

```text

under which query/intervention class,
and which external roots actually discriminate them?
```

The second formulation is still conditional, but its conditions are operationally inspectable.
