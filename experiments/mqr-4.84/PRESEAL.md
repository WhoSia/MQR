# MQR-4.84 — PRESEAL

Status: **PRESEALED / OUTCOME-BLIND / NETWORK-COHERENCE-UNDER-ATTACK / MAIN-ONLY**

## Explanandum

Let each edge in a finite comparison graph be independently licensed under MQR-4.83. 4.84 tests whether those edges can be assembled into a coherent authority network.

## Frozen network coordinates

- directed comparison edges and their scopes;
- cycle membership and path order;
- scope-indexed transitivity claims;
- local bidirectional equivalence claims;
- residual-debt routes and cycle holonomy;
- candidate cycle-breaking warrants;
- declared incomparability and missing-edge state;
- proposed completion or totalization operation;
- reopening trigger for later network inconsistency.

## Frozen nonidentities

```text
PAIRWISE_WARRANT != GLOBAL_ORDER_WARRANT
LOCAL_DOMINANCE != TRANSITIVE_DOMINANCE
BIDIRECTIONAL_LOCAL_EQUIVALENCE != GLOBAL_EQUIVALENCE_CLASS
ACYCLIC_GRAPH != WARRANTED_GLOBAL_PREORDER
PATH_COMPOSITION != AUTHORITY_COMPOSITION
DEBT_PRESERVED_ON_EACH_EDGE != DEBT_PRESERVED_AROUND_CYCLE
CYCLE_REMOVAL != SCIENTIFICALLY_WARRANTED_CYCLE_BREAKING
TOTALIZATION != AUTHORITY_COMPLETION
INCOMPARABILITY != MISSING_DATA
GLOBAL_RANKING != SCIENTIFIC_REQUIREMENT
```

## Frozen positive rule

The maximal warranted comparison structure is the largest explicitly scoped subgraph for which every retained path composition preserves direction, scope, equivalence ancestry and residual-debt routing. Edges that fail these tests remain visible as cycles, fractures, debt holonomy, reversals or incomparability. No completion step may add authority merely by selecting a total order.

## Forbidden moves

- rank all certificates by edge count, depth, or a scalar score;
- infer transitivity from adjacent pairwise passes;
- collapse local two-way comparison into one global equivalence class;
- delete a cycle without an independent cycle-breaking warrant;
- treat an acyclic projection as a warranted preorder;
- discharge cycle debt because each edge preserved its own debt;
- treat unconnected nodes as missing data;
- totalize a partial graph by tie-breaking alone;
- suppress later reopening after network inconsistency.

## Authority ceiling

This preseal can establish only a finite, scope-relative network-constitution result. It cannot establish a universal authority order, semantic truth, causal superiority, or novelty beyond the residue surviving prior-art reduction.
