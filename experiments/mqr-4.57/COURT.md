## Main result 1 — WCEPR does not self-transport into strategic settings

MQR-4.56 remains intact.

A WCEPR can correctly rank the challenge directions currently presented to it while the candidate set itself has already been strategically filtered.

Therefore:

~~~text
LOCAL WCEPR PASS
!=
INCENTIVE-ROBUST SEARCH.
~~~

MQR-4.57 adds a strategic-ecology receipt around WCEPR rather than replacing WCEPR.

## Main result 2 — observed challenge supply is endogenous

The withholding and stuffing witnesses separate:

~~~text
OBSERVED CHALLENGE SET
AVAILABLE CHALLENGE SET
STRATEGICALLY SUPPLIED CHALLENGE SET
~~~

A material challenge can be absent because:
- an incumbent withholds it;
- the reward system discourages it;
- its cost is strategically inflated;
- the target is framed so it appears irrelevant.

Conversely, a challenge family can be numerically large because one incentive lineage generates many nominal variants.

Therefore:

~~~text
OBSERVED SUPPLY
!=
EXOGENOUS FRONTIER.
~~~

## Main result 3 — reported cost is not a scientific oracle

Opportunity-cost reasoning in MQR-4.56 remains usable only if its inputs are auditable.

The Court shows that agents can:
- under-report cost to win attention;
- inflate cost to exclude exterior challenges;
- shift private effort into proposal/positioning activity induced by the institution.

Thus:

~~~text
REPORTED COST
!=
REALIZED COST
!=
SOCIAL OPPORTUNITY COST.
~~~

Positive authority requires prospective reconciliation where feasible.

## Main result 6 — the institution can become performative

A ranking, funding, publication or attention rule does not merely observe the scientific ecology.

It can alter:
- which projects are proposed;
- which methods are copied;
- which targets survive;
- who enters or exits;
- which costs are incurred;
- which data distribution is later used to evaluate the rule.

Thus:

~~~text
MECHANISM
CAN CHANGE
THE ECOLOGY
ON WHICH
MECHANISM IS JUDGED.
~~~

Static validation is therefore insufficient when `Φ`, the institutional feedback law, is material.
