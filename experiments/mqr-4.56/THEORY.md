# MQR-4.56 — Consequence-Expansion Policy Theory

Status: **POST-REVEAL / PRE-CLOSURE / QUALIFYING-4_OF_4-PASS / WCEPR-UNDER-PROMOTION**

## 1. The problem after openness

MQR-4.55 made consequence generation open and corrigible.

That still leaves a hard problem.

An open system can search badly.

It can:
- chase cheap separators;
- optimize novelty for its own sake;
- maximize information about the wrong model;
- repeatedly choose questions that are easy for the incumbent representation;
- overfund historically productive lanes;
- ignore option-opening challenges;
- suppress criticism of its own relevance model.

Therefore:

~~~text
OPEN SEARCH
!=
GOOD SEARCH.
~~~

## 2. Challenge value is a constitution, not a primitive

The live theoretical object is:

~~~text
Ω = (T, C, V, Q, Π_V, A, O, D, R)
~~~

Challenge value is not assumed to exist as a scalar in nature.

It is constituted relative to:
- a target/use contract;
- candidate challenge directions;
- typed value dimensions;
- comparison rules;
- provenance of value estimates;
- adversarial challenge routes;
- opportunity cost and horizon;
- drift diagnostics;
- reopening.

This makes value **endogenous but defeasible**.

## 3. Endogenous does not mean arbitrary

MQR-4.56 rejects two extremes.

### Extreme 1 — value realism by fiat
There exists one universal scientific utility function, so every possible research direction can in principle be totally ranked.

### Extreme 2 — arbitrary voluntarism
Because challenge value depends on goals and context, any preference is equally legitimate.

The live middle is stronger:

~~~text
VALUE IS
CONTRACT-RELATIVE

BUT

CONTRACT,
PROXY,
COMPARISON,
AND VALUE MODEL
CAN ALL BE
WORLD-CONTACTED
AND DEFEATED.
~~~

## 4. Why information is not enough

Expected information gain is powerful inside a constituted hypothesis/model space.

But the model space itself may be wrong or incomplete.

A highly informative experiment can:
- refine an irrelevant parameter;
- distinguish models that do not matter to the decision;
- leave a foreign rival untouched;
- exploit a representation that suppresses the missing primitive.

Thus:

~~~text
INFORMATION ABOUT M
!=
SCIENTIFIC VALUE
WHEN M ITSELF
IS UNDER CONSTITUTION.
~~~

Information remains one legitimate coordinate, not the master coordinate.

## 5. Why novelty is not enough

Novelty search supplies a powerful anti-deception lesson:
following an objective gradient can trap search.

But novelty can also drift.

A policy can discover endless new regions with little relation to the scientific target.

Therefore novelty belongs to the typed value profile as:
- escape potential;
- representation expansion;
- option opening.

It does not become a universal objective.

## 6. Scientific Goodharting

MQR-4.56 introduces a domain-specific Goodhart pattern:

~~~text
VALUE PROXY
IS DERIVED FROM
THE CURRENT TARGET / MODEL

SEARCH OPTIMIZES
THAT PROXY

SEARCH ECOLOGY
BECOMES BETTER AT
SCORING WELL

WHILE BECOMING WORSE AT
DEFEATING THE TARGET.
~~~

This is more specific than generic metric gaming.

The relevant failure is epistemic:
the challenge ecology loses access to worlds in which the incumbent value model is wrong.

## 7. Relevance drift

Target relevance is indexed.

A challenge can be relevant under:
- one claim;
- one use contract;
- one decision boundary;
- one scope.

After the contract changes, the same ordering may be stale.

Therefore every durable expansion policy needs:

~~~text
TARGET-DRIFT SENTINEL
+
VALUE-ORDER RECONSTITUTION.
~~~

Reusing yesterday's relevance ranking after the target has changed is not continuity; it is hidden inheritance.

## 8. Valuation common-mode

MQR-4.55 attacked common-mode challenge generation.

MQR-4.56 attacks common-mode challenge valuation.

A diverse portfolio can still be epistemically narrow when:
- every challenge is scored by one model;
- every scorer uses the same representation;
- every proxy inherits the same target assumptions.

Thus:

~~~text
DIVERSE CANDIDATES
+
ONE CAPTURED EVALUATOR
=
VALUATION BOTTLENECK.
~~~

The value-provenance graph `Π_V` is therefore load-bearing.

## 9. Opportunity cost and meaningfulness

Finite attention means choosing one challenge foregoes another.

Opportunity cost is unavoidable.

But numerical comparison requires:
- declared resource units;
- meaningful transformations;
- horizon;
- exchange assumptions.

MQR-4.56 therefore allows the structural fact:

~~~text
CHOOSING A
FOREGOES B
~~~

to transport more broadly than:

~~~text
A IS 2.7x
MORE VALUABLE
THAN B.
~~~

This parallels MQR-4.53:
structural transport survives more often than magnitude transport.

## 10. Option value and continuation structure

Immediate challenge value can miss future search capacity.

A modest challenge may:
- create a new instrument;
- expose a new primitive;
- unlock a new consequence family;
- establish a new morphism;
- make a previously impossible challenge cheap.

Therefore:

~~~text
CURRENT VALUE
!=
OPTION VALUE.
~~~

Option value is horizon-relative and cannot be inferred from immediate information gain alone.

## 11. The value model must be in the challenge ecology

A value constitution is scientifically illegitimate if criticism of the value model is automatically scored as irrelevant by that same model.

This creates the strongest 4.56 rule:

~~~text
THE SEARCH POLICY'S
VALUE MODEL

MUST ITSELF BE
A POSSIBLE TARGET
OF SEARCH.
~~~

WCEPR therefore includes an exterior value-challenge route and reopening law.

## 12. Local optimization survives

MQR-4.56 is not anti-optimization.

If a programme declares:
- a model;
- prior;
- utility;
- costs;
- horizon;
- action space;

then a local optimum can be meaningful and useful.

The prohibition is only:

~~~text
LOCAL OPTIMUM
UNDER DECLARED MODEL
-/->
WORLD-OPTIMAL SCIENCE.
~~~

This preserves Bayesian experimental design, value-of-computation reasoning and decision-theoretic experiment selection as legitimate local tools.

## 13. Partial orders are first-class

Some challenge profiles dominate others without weights.

Other profiles cross.

Example:

~~~text
A >= B
on every admitted dimension
and > on at least one
=> A locally dominates B

C better on information
D better on option value
=> incomparable absent calibration
~~~

MQR therefore treats incomparability as information, not as a defect to be repaired by arbitrary weighting.

## 16. Successor-facing remainder

One deeper problem remains.

A value constitution can be well formed and still face **strategic interaction**.

Other agents can:
- manipulate which challenges become available;
- hide costs;
- create decoys;
- reshape the target;
- alter the value model through institutional incentives.

Thus a possible successor debt is:

~~~text
GOOD LOCAL EXPANSION POLICY
!=
ROBUST MULTI-AGENT
DISCOVERY ECOLOGY.
~~~

That issue does not reopen MQR-4.56.
