## Governing question

Let `E` be the currently available expansion directions admitted by WCCFR.

A policy can be active, diverse, non-common-mode and reopenable while still repeatedly selecting challenges that are:
- cheap but scientifically weak;
- maximally novel but target-irrelevant;
- highly informative about an internal model but irrelevant to the decision/use contract;
- easy to score under the incumbent representation;
- adversarially generated to consume attention without threatening any authority claim;
- attractive only because the value proxy is itself produced by the target theory;
- locally useful but globally opportunity-cost dominated.

The question is:

> Can an open consequence ecology prefer some expansion directions over others without pretending that all future scientific value is represented by one fixed utility function?

## Frozen admissibility obligations

### A1 — Target contract declaration
Every preference claim must name the target/use/authority contract relative to which relevance is assessed.

### A2 — Typed value profile
Information gain, separation power, actionability, novelty, cost and option value may not be silently collapsed.

### A3 — Proxy provenance
Every optimized challenge-value proxy must expose how it was produced and whether it shares assumptions with the target.

### A4 — Anti-Goodhart audit
The policy must include a witness that improving the selected proxy can fail to improve the scientific target.

### A5 — Target-drift sentinel
The policy must detect when repeated search changes the practical/semantic target enough that the old relevance ordering is no longer licensed.

### A6 — Adversarial decoy resistance
A generator capable of flooding the candidate set with cheap, novel or high-scoring but nonmaterial challenges must not automatically dominate attention.

### A7 — Opportunity-cost declaration
Preference requires an explicit resource/horizon model. “Better” without a cost/opportunity surface is at most a local structural comparison.

### A8 — Unit/reparameterization audit
A preference may not depend solely on arbitrary rescaling of cost or proxy units.

### A9 — Non-myopic option value
A challenge that opens new consequence classes may have value not captured by immediate information or authority gain.

### A10 — Common-mode value audit
Independent challenge contents may still share one value estimator or one target-dependent scoring model.

### A11 — Model-relative optimizer ceiling
A unique optimum is allowed only relative to an explicitly constituted local prior/utility/cost model.

### A12 — Value-constitution reopening
World contact that defeats the current relevance or value model must be able to revise `V/Q` without being treated as mere poor performance under the old metric.

## Frozen countermodel bank

### CM1 — Cheap-challenge trap
A policy ranks challenges by separators-per-cost. Many trivial cheap separators dominate one expensive challenge that alone threatens the load-bearing authority claim.

Pressure:
`yield / cost` is not universal scientific value.

### CM2 — Information–relevance divergence
Challenge A produces higher expected information gain about a model parameter. Challenge B produces lower information gain but directly separates the decision-relevant rival.

Pressure:
information gain does not total-order challenge value.

### CM3 — Novelty drift
A novelty-maximizing policy continually reaches new behavioral regions while moving farther from the declared scientific target.

Pressure:
novelty is an escape generator, not a universal value function.

### CM4 — Incumbent-proxy Goodhart
A target theory supplies the representation used to score “challenge quality.” Optimization concentrates on regions the theory represents well and suppresses a foreign separator.

Pressure:
challenge-value estimation can inherit target capture.

### CM5 — Target-relevance drift
An initially relevant challenge class remains highly scored after the claim/use contract changes.

Pressure:
relevance order is temporally/semantically indexed.

### CM6 — Adversarial decoy flood
An adversary generates thousands of cheap, independent, high-proxy challenges that cannot alter any live claim/use/decision boundary.

Pressure:
candidate multiplicity and independence do not imply attention priority.

### CM7 — Common evaluator capture
Two challenge generators are ancestry-independent, but both are ranked by one value model with the same blind spot.

Pressure:
generator diversity does not imply valuation diversity.

### CM8 — Cost-unit rank reversal
Two challenges reverse order under a scientifically meaningless change of cost units because an unnormalized weighted scalar is used.

Pressure:
opportunity-cost comparisons need meaningfulness / unit discipline.

### CM9 — Horizon reversal
A short-horizon policy prefers immediate local gain; a longer-horizon policy prefers an option-opening challenge.

Pressure:
challenge preference is horizon-relative when future search routes matter.

### CM10 — Actionability divergence
A challenge strongly separates models but cannot change any declared action/use decision; another weaker separator changes the decision boundary.

Pressure:
separation power does not equal practical scientific value.

### CM11 — Surprise trap
A challenge with extremely surprising outcome dominates ranking, even though it concerns a peripheral auxiliary variable.

Pressure:
surprise is not importance.

### CM12 — Sunk-yield lock-in
A generator that has historically produced many useful challenges receives ever more attention despite fresh evidence that another route now has greater escape capacity.

Pressure:
past productivity is not stationary future value.

### CM13 — Value-model self-insulation
A challenge that criticizes the value model itself is scored as irrelevant by that same value model.

Pressure:
a scientific search policy cannot constitutionally exempt its own relevance machinery.

### CM14 — Equal current value / unequal option structure
Two challenges have equal current relevance, information and cost, but only one unlocks a new independent challenge family.

Pressure:
current-value equality does not imply equal continuation value.

### PW4 — Adversarial-decoy rejection
A high-count/high-novelty/high-proxy decoy family loses priority because it cannot touch a live authority/use boundary and is common-mode in value provenance.

Expected:
attention can resist proxy flooding without a universal utility.

### PW5 — Option-opening challenge
A challenge with modest immediate value is admitted because it prospectively unlocks a new independent consequence family under a declared horizon.

Expected:
continuation/option value can matter without being collapsed into current information gain.

### PW6 — World-contacted value-model revision
A value model predicts that one challenge family is superior; prospective outcomes repeatedly violate the predicted decision/escape effect; the value constitution is revised.

Expected:
the search policy itself remains defeasible.

## Frozen primary hypotheses

### H1 — No universal challenge-value scalar is licensed for free
An open consequence ecology plus finite resources does not identify one representation-invariant, domain-general scientific utility function.

### H2 — Some local challenge preferences are nevertheless earnable
Dominance, contract-specific utilities, hard relevance constraints, option-opening relations and declared-model expected utility can provide local guidance.

### H3 — Challenge value is endogenous but not arbitrary
Value depends on target, use, horizon, opportunity cost and consequence ecology, yet can still be world-contacted and defeated.

### H4 — Exploration Goodharting is structurally possible
Optimizing a challenge proxy can systematically improve the proxy while degrading target-relevant scientific search.

### H5 — Target relevance is reopenable
A relevance relation can lose authority when the target/use constitution changes.

### H6 — Value-estimator ancestry matters
A diverse challenge portfolio can remain common-mode if all directions are evaluated by the same captured value model.

### H7 — Opportunity cost transports structurally more easily than magnitudes
The need to account for foregone alternatives may transport across domains while numerical exchange rates generally do not.

### H8 — The value constitution must be criticizable from outside itself
A search policy that cannot admit challenges to its own relevance/value machinery is constitutionally closed.
