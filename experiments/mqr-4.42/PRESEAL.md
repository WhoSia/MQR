## Explanandum lock

Can a frontier-relative contact rank guide science when:
- rival hypotheses/models/states are generated by fallible procedures;
- the query/intervention language itself can omit discriminating directions;
- new rivals may emerge outside the current representation;
- no finite search can enumerate all scientifically relevant alternatives?

The court must not replace one hidden ontology ("empirical degrees") with another hidden ontology ("complete rival frontier").

## Candidate objects

### 1. Rival Generator

A procedure, source or transformation that can propose a rival relevant to a target claim.

Generator classes may include:
- theory-derived;
- residual/anomaly-derived;
- mechanism mutation;
- representation mutation;
- adversarial construction;
- external-case transfer;
- instrument-failure/common-cause construction;
- random/systematic search over a declared grammar.

A generator is not automatically an independent epistemic source.

### 2. Rival-Generation Ancestry Graph (RGAG)

Track shared assumptions, code, source evidence, representation and search heuristics across generators.

```text
GENERATOR DIVERSITY != GENERATOR INDEPENDENCE
```

### 3. Frontier Adequacy Surface (FAS)

A frontier receipt is indexed to:

```text
claim scope C
query/intervention class Q
generator portfolio G
generator ancestry A
admission rule M
current rival set F
discovery history H
```

It does not claim exhaustive world coverage.

### 4. Frontier Escape Witness (FEW)

A new rival is a frontier escape when it is claim-relevant but was not generated/admitted by the frozen frontier procedure and changes at least one load-bearing surface:

- adds an RSO;
- defeats query closure;
- changes FCR;
- changes authority state;
- exposes generator-common-mode failure.

### 5. Generator-Relative Saturation

Repeated valid searches with no admitted new rival may support:

```text
SATURATED RELATIVE TO (G,Q,M,H)
```

but never:

```text
NO FURTHER SCIENTIFICALLY RELEVANT RIVAL EXISTS.
```

### 6. Discovery-Impact Vector

Do not compress discovery value to one scalar.

For a newly admitted rival r:

```text
D(r) = {
  new_obligations,
  query_escape,
  fcr_delta,
  authority_change,
  root_reuse_or_expansion,
  generator_ancestry_novelty,
  representation_escape
}
```

A rival can have high scientific value even when FCR does not change.

## Frozen attacks

### Attack 1 — Generator Portfolio Dependence

Construct two plausible generator portfolios G1 and G2 over the same claim/world-facing evidence.

If they yield nonnested frontiers and different RSOs/FCRs:

```text
FRONTIER ADEQUACY IS GENERATOR-RELATIVE.
```

### Attack 2 — Generator Common-Mode

Use nominally different generators that share the same model class, residual transform or representation.

Agreement/no-new-rival across them must not count as independent closure evidence.

### Attack 3 — Query-Closure Failure

Freeze Q such that all current rivals are separable.

Construct an off-Q rival that aliases every current rival on Q but diverges under an admissible extension Q+.

Target:

```text
CURRENT-RIVAL QUERY SEPARATION != QUERY-LANGUAGE CLOSURE.
```

### Attack 4 — Representation Escape

A rival may be unavailable in the current ontology/parameterization yet become expressible after a representation expansion.

Target:

```text
GENERATOR FAILURE != RIVAL ABSENCE.
```

### Attack 5 — Frontier Escape with Stable FCR

Admit a new rival that creates a new obligation already covered by the existing root basis.

Then:

```text
FCR DELTA = 0
but
FRONTIER KNOWLEDGE CHANGED.
```

Therefore discovery value cannot be identified with rank increase.

### Attack 6 — Frontier Escape with Rank Increase

Admit a new rival whose obligation requires a fresh root.

```text
FCR: 1 -> 2
```

This demonstrates genuine world-contact expansion.

### Attack 7 — Frontier Escape with Authority Failure but Stable Rank

A new rival is distinguishable by an existing root but defeats a load-bearing interpretation/ancestry assumption.

Then authority can reopen while root cardinality stays fixed.

### Attack 8 — Saturation Mirage

Run many searches from one generator family and observe no new rivals.

Then introduce a generator with distinct ancestry that finds one immediately.

Target:

```text
SEARCH COUNT != FRONTIER COMPLETENESS.
```

### Attack 9 — Admission-Rule Dependence

Hold generated candidates fixed but change a reasonable admission rule (e.g. materiality threshold, claim relevance, empirical testability).

If the admitted frontier changes, the receipt must expose admission governance.

### Attack 10 — Post-Selection Rival Search

If generator tuning uses the same evidence used to adjudicate its rivals, apparent discovery performance may be selection-contaminated.

Target:

```text
RIVAL GENERATION SUCCESS != INDEPENDENT DEFEAT PRESSURE.
```

### Attack 11 — Adversarial Generator Overfit

A generator can produce rivals tailored to current tests that disappear under held-out query extension.

Adversariality is useful only if it survives nontrivial held-out discrimination.

### Attack 12 — Discovery Value without Rank Delta

New rival R adds no new root and no FCR change but:
- partitions an old equivalence class;
- changes mechanism attribution;
- changes transport scope;
- creates a new future discriminator target.

Therefore:

```text
DISCOVERY VALUE != DELTA FCR.
```

### Attack 13 — Rank Increase without High Discovery Value

A contrived rival may force an extra root yet be weakly motivated or outside claim relevance.

Therefore:

```text
DELTA FCR != DISCOVERY VALUE.
```

### Attack 14 — Finite Grammar Closure

If rival generation occurs inside a finite declared grammar, exhaustive enumeration can certify closure only of that grammar.

```text
GRAMMAR CLOSURE != SCIENTIFIC FRONTIER CLOSURE.
```

### Attack 15 — Successor Query Injection

A new measurement/intervention technology creates Q+ and reveals distinctions not expressible under Q.

Frontier adequacy must reopen even if no new theory generator changed.

### Attack 16 — Generator Retirement Hazard

Retiring a generator because it has recently produced no new rivals may erase the only route to a class of future frontier escapes.

Saturation is not sufficient retirement evidence.

## Frozen outcome branches

```text
A. FRONTIER-CERTIFIABLE:
   a finite scientific frontier can be certified adequate in a representation-independent sense.

B. GENERATOR-RELATIVE:
   adequacy can only be stated relative to explicit generator/query/admission contracts.

C. SATURATION-RELATIVE:
   repeated no-discovery can support local generator-relative saturation but not closure.

D. ESCAPE-SENSITIVE:
   frontier receipts must reopen under rival, query, representation or generator escape.

E. RANK-GUIDING:
   FCR remains useful as a conditional action/research guide when its frontier receipt is explicit.

   FCR should not guide science because frontier uncertainty destroys its operational value.

   discovery value is multidimensional and cannot be reduced to delta-rank.
```

Compatible branches may co-occur only with explicit scope.
