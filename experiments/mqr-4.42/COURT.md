## Executable attacks

### Generator portfolio dependence

Two plausible portfolios over the same top-level claim admit nonnested frontiers:

```text
portfolio A -> r0 + ra
portfolio B -> r0 + rb
```

The frontier is generator-relative.

### Generator common-mode

Frozen witness:

```text
generator_count = 2
generator_ancestry_count = 1
generator_common_mode_detected = YES
```

Generator count does not establish independent rival search.

### Query-closure failure

The base query separates admitted current rivals, yet a successor rival aliases them on the base query and separates only under an admissible extension:

```text
CURRENT-RIVAL SEPARATION != QUERY-LANGUAGE CLOSURE
```

### Saturation mirage

One generator can return NO_NEW repeatedly while a distinct-ancestry generator immediately discovers a rival:

```text
SEARCH COUNT != FRONTIER COMPLETENESS
```

No-discovery supports at most generator-relative saturation.

### Stable-rank escape

```text
escape = YES
off_query_escape = YES
FCR 1 -> 1
```

The frontier changes while contact rank does not.

```text
STABLE FCR != ZERO DISCOVERY VALUE
```

### Rank-increasing escape

```text
FCR 1 -> 2
```

Some frontier escapes genuinely require additional external world contact. Rank increase alone still does not identify scientific discovery value.

### Finite grammar closure

A declared finite grammar may be CLOSED while the evaluator still emits:

```text
frontier.world_complete=NO
```

Thus exhaustive enumeration of a declared grammar is not scientific-frontier closure.

## Positive result candidate — conditional guidance survives

A frontier-relative rank can remain locally useful when:
- generator/query/admission provenance is explicit;
- current rival/query relations are auditable;
- generator common-mode is exposed;
- world completeness is denied;
- a live reopening reserve exists;
- any admitted escape forces reopening.

Lean contains a finite witness with:

```text
LOCAL GUIDANCE = ADMISSIBLE
WORLD FRONTIER COMPLETE = FALSE
REOPEN ON ESCAPE = TRUE
```

This is the positive center of 4.42.

## Open Frontier Receipt

- claim scope;

- generator portfolio;
- Rival-Generation Ancestry Graph;
- admission rule;
- admitted rival set;
- discovery history;
- finite grammar state;
- current FCR relation;
- explicit `world_complete=NO`.

OFR is a current-surface receipt, not a closure theorem.

## Frontier Reopening Reserve

FRR preserves live routes for:
- new rival generators;
- ancestry diversification;
- query/intervention extension;
- representation escape;
- residual/anomaly search;
- external-case replay;
- root/instrument challenge.

A low current FCR without a credible reopening reserve cannot turn silence into completeness.
