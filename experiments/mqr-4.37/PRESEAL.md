## Frozen attacks

### 1. Finite-Closure Quantifier Attack

Construct prospectively nested declared probe classes:

```text
P1 ⊂ P2 ⊂ P3
```

and require a countermodel in which:

```text
R_int(P1) = 0
R_int(P2) > 0
```

without contradiction.

Target failure: **Quantifier-Scope Laundering Problem**.

A zero-residue claim may not inherit authority outside the exact quantifier that generated it.

### 2. Premise-Ancestry Granularity Attack

Compare:

```text
R1, R2, ..., Rn -> P_empirical -> phi
```

against a compressed graph in which only `P_empirical` is visible.

Construct two receipt ancestries that compile to the same coarse premise label while differing in a load-bearing world-facing assumption.

Target failure: **Receipt Compression Paradox**.

### 3. Kernel–World Frontier Migration Attack

Move a deterministic transformation/calibration algebra from the world-facing preprocessing side into a checked formal region.

Require the court to distinguish:

```text
FORMAL_REGION_EXPANDS
```

from:

```text
WORLD_ADEQUACY_IMPROVES
```

Target failure: **Epistemic Debt Concentration Problem**.

The court must not represent "more formalized" as "closer to truth."

### 4. Checker-Independence Stress

Freeze independence as a vector:

```text
I = (
  I_statement,
  I_compiler,
  I_kernel,
  I_world
)
```

A checker-plurality PASS may raise proof-custody robustness only along the coordinates actually varied.

Construct a case where two formal checkers accept the same derivation while a shared statement/encoding defect remains.
