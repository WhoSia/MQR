# MQR-4.72 — Intentional Contact & Truth Court Constitution

Status: **PRE-RESULT / NATURAL-SCIENCE-FIRST / EXPLORATORY-INTENTIONALITY-ATTACK / MATHEMATICAL-FRAMEWORK-CONTROL**

## Purpose

Test whether inquiry authority can be inherited by preserving only:
- target labels;
- procedures;
- representations;
- institutional acceptance.

Primary hypothesis:

> Authority inheritance requires preservation of a relevant defeat/contact route. Full target ontology is not always required, but some structured directedness and defeasibility relation is.

## Natural-science cases

### N1 — calibrated target measurement
Specific target quantity, valid calibration, independent contact route.
Expected: ADMIT_LOCAL.

### N2 — same indication, different target semantics
Same raw indication and representation as N1, but intended quantity differs and calibration map differs.
Expected: DISTINCT_OUTCOME_SEMANTICS.

### N3 — exploratory experiment
No mature target ontology; explicit structured goal is mapping variation/stability under controlled manipulation.
Reproducible contact and exterior anomaly route are present.
Expected: ADMIT_EXPLORATORY.

### N4 — theory-controlled reliability loop
The theory under test is the sole reason for discarding discordant data.
No independent calibration/background route.
Expected: HOLD_CIRCULAR.

### N5 — theory-guided reliability with independent support
Theory guides reliability judgment, but calibration / background support is independently warranted.
Expected: ADMIT_WITH_DEPENDENCE_RECEIPT.

### N6 — procedure preserved, defeat route lost
Same procedure and target label are inherited, but the new apparatus cannot expose the old failure mode.
Expected: DOWNGRADE_INHERITED_AUTHORITY.

## Mathematical cases

### M1 — theorem inside declared framework
Proposition P is derivable under framework F and semantics are fixed.
Expected: CERTIFY_RELATIVE.

### M2 — same theorem label transported to non-equivalent framework
The syntactic theorem label is retained but target semantics/framework change.
A countermodel exists under the target framework.
Expected: HOLD_TRANSPORT.

### M3 — framework extension preserving proof and semantics
An explicit embedding preserves premises, proof steps and interpretation.
Expected: CERTIFY_TRANSPORT_RELATIVE.

### M4 — derivability preserved, semantic scope changed
A formula remains derivable syntactically after reinterpretation, but the interpreted proposition differs.
Expected: HOLD_SEMANTIC_DRIFT.

### M5 — computer-assisted proof with independently checked kernel
Opaque search/computation may occur, but final certificate is checked against an independently specified proof kernel/framework.
Expected: CERTIFY_RELATIVE.

## Strong counterpressure

```text
FULL TARGET ONTOLOGY

FOR LEGITIMATE SCIENTIFIC CONTACT
```

Candidate replacement:

```text
STRUCTURED DIRECTEDNESS
+

+
DEFEATABILITY
```

## Common inheritance criterion candidate

An inherited authority claim survives only if at least one of the following is established:

1. the old defeat route remains available;
2. an explicit transport proof maps the old defeat obligation into the new system;
3. an independently stronger route dominates the old one for the declared scope.

Label/procedure continuity alone is insufficient.

## Claim ceiling

This Court does not establish a universal theory of scientific or mathematical truth.

It tests only scope-relative authority transport and anti-circularity.
