## Core object: authority-loss contract

For a compression candidate `q`, scientific context `c`, horizon `h`, and loss coordinate `i`:

`L_i(q | c,h)`

denotes the typed authority loss attributed to that compression under the frozen semantics.

A loss contract is not only a ceiling vector. It is a warrant-bearing object:

`C = (I, B, V, R, W, H, X)`

where:

- `I` — typed loss coordinates;
- `B` — coordinate-local tolerability ceilings;
- `V` — hard-veto predicates, if any;
- `R` — reopening / re-expansion dominance predicates;
- `W` — warrant ledger for each ceiling/veto/reopening rule;
- `H` — horizon/scope declaration;
- `X` — expiry and revision conditions.

No global loss score is primitive.

## Warrant ledger

Every nontrivial tolerance rule must carry at least:

- target coordinate;
- context predicate;
- horizon;
- evidence kind;
- source/provenance;
- reason the loss is tolerable or intolerable;
- whether the rule is descriptive, normative, operational, or merely exploratory;
- known defeaters;
- expiry/review condition;
- authorized revision trigger.

A bare value such as `REOPEN <= MATERIAL` is therefore incomplete as a scientific contract.

## Scalarization court

The scalar attack must include at least:

1. positive weighted sums over monotone encodings;
2. context-dependent weights;
3. nonlinear monotone scalarizations;
4. lexicographic / sufficiently-large-weight representations;
5. penalty-method encodings of vetoes;

The question is not merely whether a scalar can reproduce a finite verdict table.

The Court separates:

- **representational reducibility** — some scalar/constrained formalism reproduces the verdicts;
- **authority reducibility** — the scientific warrant for the scalar/objective/constraint ordering is independently established.

A finite lookup-table scalar representation counts only as representational reducibility.

## Endogenous tolerance revision

4.68 explicitly allows the possibility that tolerances should change.

Candidate revision object:

`Rev(C, E) -> C'`

where `E` is new evidence or a scope/horizon change.

A revision is admissible only if the frozen revision constitution licenses the type of update.

Predeclared forbidden revision motives:

- observed favorable compression ratio alone;
- failure to obtain a desired lossy candidate;
- desire to match a preferred scalar baseline;
- retrospective relabeling of FATAL/MATERIAL solely to avoid reopening;
- changing a ceiling after seeing the tested candidate's loss profile without an independently frozen trigger.

The Court must test whether all legitimate revision can be reduced to ordinary preference/constraint revision.
