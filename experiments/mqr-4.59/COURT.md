## Main result 1 — the 4.58 anti-inflation rule survives only as a heuristic

MQR-4.58 used:

~~~text
NEW EXECUTABLE DISTINCTION
OR NEW WORLD-CONTACT ROUTE
OR REAL OPERATIONAL REPAIR
=> PROMOTION CANDIDATE
~~~

MQR-4.59 preserves its anti-inflation intent but rejects necessity and sufficiency.

False negatives include:
- consequence-preserving simplification;
- live-claim narrowing;
- material failure localization;
- authority-scope correction;
- future option opening.

False positives include:
- formal-only executable branches;
- duplicate world-contact routes;
- engineering-only repairs;
- repeated restatements.

Therefore:

~~~text
ADDITIVE NOVELTY
!=
EPISTEMIC ADVANCE

AND

NO ADDITIVE NOVELTY
!=
NO EPISTEMIC ADVANCE.
~~~

## Main result 2 — promotion is not scientific progress

The Court distinguishes:

~~~text
WHAT COUNTS AS
SCIENTIFIC PROGRESS?

!=

SHOULD THIS SUCCESSOR
ALTER THE LIVE
CONSTITUTION?
~~~

RPAR addresses the second question only.

It does not define truthlikeness, understanding, knowledge, problem-solving success or one final scientific aim.

## Main result 3 — subtraction can be epistemically positive

A successor can improve the live constitution by:
- deleting a false primitive;
- compressing duplicated machinery;
- narrowing an overclaimed authority region;
- eliminating a live claim;
- separating an invalid authority cast.

Thus:

~~~text
LESS CONSTITUTION
CAN BE
MORE WARRANT.
~~~

This is not a universal preference for simplicity.

Subtraction must preserve the relevant warranted consequences or discharge a live defect.

## Main result 4 — execution is evidence of maturity, not a universal gate

Executable realization can:
- expose ambiguity;
- support prospective checking;
- make failure reproducible.

But a universal execution gate would undercount:
- eliminative results;
- conceptual corrections;
- safe ontology deletion;
- authority-scope repair;
- diagnostic localization.

Therefore:

~~~text
EXECUTABLE
!=
PROMOTION-WORTHY BY DEFAULT

NON-EXECUTABLE
!=
EPISTEMICALLY EMPTY BY DEFAULT.
~~~

## Main result 5 — world-contact novelty requires independence

A nominally new sensor, dataset, benchmark or probe route may still be common-mode with an old route.

New route labels do not establish new authority.

A materially independent route must differ in relevant ancestry, intervention surface or defeat profile.

## Main result 8 — failure localization is a first-class promotion route

A successor may leave current predictions unchanged while making future error attribution materially sharper.

If this changes:

- which subsystem should be reopened;
- which authority is defeated;
