# Real-Language v0.7 — World-Contact Substitution Boundary
Status: EXECUTABLE CANDIDATE / MQR-4.40

v0.7 replaces the universal v0.6 direct-receipt requirement with a conditional **World-Contact Substitution Certificate (WCSC)**.

Claim classes: TRANSPORT_ONLY / BASIS_GENERATED / NEW_EMPIRICAL. Only the first two are substitution-eligible.

A **World-Contact Basis (WCB)** declares load-bearing empirical degrees and EXTERNAL roots covering them. The checker can compute a minimum root cover relative to that declared graph; this is not a truth score and does not prove the degree decomposition complete or independent.

An **External Root Cut (ERC)** requires every load-bearing justification node reachable from the endpoint to have a path to an EXTERNAL root. Internal cycles may exist, but unanchored SCCs cannot justify substitution.

Endpoint queries must be generated from root-anchored queries through declared bridge maps. Naturality receipts are DEFINITIONAL / FORMAL_EXACT / EMPIRICAL / SELF / UNTESTED; empirical naturality must itself point to an external root.

Alternative paths require explicit agreement. Path agreement is coherence evidence, not independent world contact. With multiple paths, equivalence must survive PRE and POST extension. Higher coherence is CLOSED / FINITE_ONLY / OPEN; only CLOSED earns PASS for the declared diagram class.

Roots are LIVE / STALE / EXPIRED. Derived receipts never refresh them.

\`direct_receipt ABSENT\` is compatible with substitution PASS. Later direct HOLD/FAIL reopens substitution to HOLD; direct evidence is a defeat route, not an infallible oracle.

Live coordinates: EXTERNAL_ROOT, WORLD_CONTACT_BASIS, QUERY_BASIS, NATURALITY, PATH_INDEPENDENCE, CONGRUENCE, HIGHER_COHERENCE, ANCESTRY, NO_NEW_EMPIRICAL_DEGREE, DEFEAT_TO_WORLD, EXTERIORITY, BRIDGE_STATE, GLOBAL_NONAMPLIFICATION, DIRECT_CONFLICT.

A PASS means only **WORLD_CONTACT_BASIS_PRESERVING_NONAMPLIFYING SUBSTITUTION ADMISSIBILITY**.

FRESH DIRECT ENDPOINT CONTACT IS NOT REQUIRED PER TRANSFORMATION.
WORLD CONTACT IS REQUIRED FOR EACH INDEPENDENT LOAD-BEARING EMPIRICAL DEGREE THE CLAIM ADDS.
INTERNAL COHERENCE DOES NOT CREATE WORLD CONTACT.
DERIVED RECEIPTS DO NOT REFRESH WORLD ROOTS.
FINAL_TRUTH_DISTANCE = UNIDENTIFIED.
