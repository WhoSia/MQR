# Real-Language v0.22 — World-Contact Consequence-Family Constitution

Status: **EXECUTABLE-CANDIDATE / MQR-4.55 / PRESEALED / NOT-YET-PROMOTED**

## Purpose

REALCONSEQUENCE 0.22 serializes the **constitution of the consequence family used to test a scientific authority claim**.

It does not count tests as authority.

It records whether the current consequence ecology has:
- typed channels;
- explicit ancestry/common-mode audit;
- a declared generator grammar;
- a live off-grammar proposal route;
- prospective adversarial expansion;
- serialization-invariant consequence classes;
- exposed tacit-competence obligations;
- a non-self-authorizing heuristic role;
- holdout capacity or an explicit justified unavailability;
- active reopening;
- no world-completeness overclaim.

## Core boundary

~~~text
MORE TESTS
!=
MORE INDEPENDENCE
!=
MORE ADEQUACY
!=
MORE AUTHORITY
~~~

Raw test count is intentionally absent from the authority calculation.

## Rigor / intuition boundary

~~~text
HEURISTIC GENERATION
CAN BE ADMISSIBLE

WITHOUT

HEURISTIC SELF-AUTHORITY.
~~~

A heuristic, diagram, analogy, model manipulation or tacit expert judgment may generate a candidate consequence. It cannot set the candidate's own scientific verdict.

Likewise:

~~~text
FORMAL CORRECTNESS
WITHIN A DECLARED LANGUAGE
!=
WORLD CONSEQUENCE-FAMILY COMPLETENESS.
~~~

## WCCFR

The executable candidate is **WCCFR — World-Contact Consequence-Family Receipt**.

A successful packet may emit:

~~~text
consequence.local_adequacy=YES
consequence.wccfr=EARNED_LOCAL_CANDIDATE
consequence.world_family_complete=NO
~~~

This is deliberate.

Local adequacy is earned only while the family remains explicitly open to consequence discovery.

## Tacit competence

`RECONSTRUCTIBLE` is a first-class state.

The language rejects both:
- protocol fetishism: text/code custody is not automatically discriminatory competence;
- tacit mysticism: missing skill is not automatically ineffable or permanently non-transferable.

## Holdout

`UNAVAILABLE_JUSTIFIED` is allowed because some scientific settings do not support a clean held-out consequence generator.

This does not equal `AVAILABLE`. It merely prevents the language from fabricating independence where the domain does not permit it.

## Claim ceiling

REALCONSEQUENCE 0.22 does not establish:
- world consequence completeness;
- a universal scientific-discovery algorithm;
- an intuition oracle;
- independence merely from expert headcount;
- completeness merely from formal proof;
- unique optimal rigor/intuition balance.

Promotion requires the qualifying MQR-4.55 Court and proof boundary.
