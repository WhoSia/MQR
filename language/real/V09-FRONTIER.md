# Real-Language v0.9 — Open Rival-Frontier Governance

Status: EXECUTABLE / MQR-4.42 / OPEN FRONTIER / CONDITIONAL GUIDANCE / WORLD COMPLETENESS FORBIDDEN

## Problem

MQR-4.41 computes a Frontier-Relative Contact Rank (FCR) once a live rival frontier is supplied. MQR-4.42 moves one layer upstream: the rival frontier is itself produced by fallible search, representation, query and admission procedures.

A finite optimizer cannot repair an impoverished frontier merely by solving that frontier exactly.

## Open Frontier Receipt (OFR)

An OFR records the finite surface on which a frontier statement is licensed:

```text
claim scope
query/intervention class
generator portfolio
generator ancestry
admission rule
admitted rival set
discovery/search history
finite grammar state
current FCR surface
```

OFR never means that the world frontier is complete.

## Frontier Reopening Reserve (FRR)

FRR is the maintained ability to reopen the frontier through live escape routes:
- rival-generator diversification;
- query/intervention extension;
- representation mutation;
- residual/anomaly generation;
- external-case transfer;
- instrument/common-cause challenge;
- controlled relaxation of a finite grammar or search boundary.

FRR is not a scalar and is not a completeness probability.

## Frontier Escape Witness

A newly admitted rival is a frontier escape when it lies outside the frozen frontier procedure and changes at least one load-bearing surface: an RSO, query closure, FCR, authority state, generator-common-mode diagnosis, or representation/discriminator target.

## Generator-relative saturation

Repeated valid search with no new admitted rival can establish only:

```text
SATURATED RELATIVE TO (G,Q,M,H)
```

It cannot establish:

```text
NO FURTHER SCIENTIFICALLY RELEVANT RIVAL EXISTS
```

## Conditional FCR guidance

FCR may guide local experiment allocation, discriminator design or world-contact planning when:
1. OFR is explicit;
2. current rival/query relations are auditable;
3. generator ancestry is exposed;
4. admission governance is visible;
5. world completeness is denied;
6. FRR remains live;
7. any admitted escape reopens implicated rank and authority receipts.

This is local conditional guidance, not frontier certification.

## Discovery impact

Discovery value is vector-valued:

```text
D(r) = {
  new obligations,
  query escape,
  FCR delta,
  authority change,
  root reuse / expansion,
  generator-ancestry novelty,
  representation escape
}
```

No scalar discovery score is authorized.
