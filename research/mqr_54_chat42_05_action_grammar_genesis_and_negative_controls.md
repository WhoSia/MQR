## Formal setting and a conditional proposition

A hypothetical analyst knows one shared finite world S={0,1,2,3}, deterministic total state transformations f:S→S, and a readout sensor o:S→O. A laboratory initially has primitive action maps A; the *actually executable finite words* form its generated transformation monoid M=〈A〉 (including identity). The resulting observational equivalence relation is

\[
s\equiv_M t \iff \forall f\in M,\quad o(f(s))=o(f(t)).
\]

A newly proposed action h is **operationally new relative to the old lab** only if h∉M, not merely if it is given a different label. The scientist's actual ability to execute it is an *external empirical certificate*, not something generated by the toy simulator. Under that certificate, the new operational language is M'=〈A∪{h}〉. The newly realized experimental repertoire strictly refines the observational partition precisely when

\[
\exists s,t\ (s\equiv_M t \land \exists f\in M'\;o(f(s))\neq o(f(t))).
\]

This is immediate from the definition of observational equivalence (a useful **criterion**, not an original general theorem). Because M⊆M', E_M' always refines or equals E_M. **A new operation h∉M does not imply E_M'≺E_M.** The ability to perform a new physical procedure and the discovery of a previously inaccessible observational distinction are separate achievements.

## Concrete four-preparation witness and two null controls

Take o=(dark,dark,bright,bright) and an old action f=(1,0,3,2), which swaps states within the two original observational classes. The closure M={id,f}; the old partition is {{0,1},{2,3}}.

**Positive:** Add h=(0,2,1,3), a cross-class swap. It is not in M, and the new monoid has **8** transformations. Already the single action h yields `o(h(0))=dark` and `o(h(1))=bright`; the new observational partition is **four singletons**, strictly refining the original two classes.

**Negative A — new executable operation, no new observable:** Add k=(1,0,2,3), which swaps only states 0 and 1. This mapping is not in the old 2-map monoid; after adding it the closure has **4** maps, but it preserves {{0,1},{2,3}}. Thus *new capability does not automatically create a new conceptually useful observation*.

**Negative B — merely a new name:** Re-enter f using an alternative name. Its map already belongs to M, so it is not new capability nor new discrimination. Syntactic novelty is not operational novelty.

**Negative C — one fixed sensor can be utterly uninformative:** If o(s)=constant for every s, then for all actions f:S→S, o∘f is also constant; no repertoire of deterministic state transformations using this sole sensor can distinguish any two states. **A new detector/readout coupling**, not just another manipulation, is required to make new distinctions. This is a mathematical impossibility result for this defined model, not a general physical impossibility for richer sensor systems.

**Negative D — contact has not actually been verified:** New h is proposed but `externally_certified_executable=False`; the model intentionally preserves the old partition. A Boolean flag is not the evidence of an actual validated physical transfer. Any report claiming that two independent sciences carried out a new joint experiment based solely on the flag is unsupported.

## Full four-state transformation census

There are 4^4=**256** deterministic total maps S→S (including non-invertible transformations), and the old monoid has 2 maps.

- **2** maps already in the old monoid: not new.
- **254** maps new relative to the original executable closure.
- **192** choices yield a strict refinement of the initial observational equivalence (for these particular sensor/old actions).
- **62** maps are operationally new but leave the observational equivalence unchanged.
- Hence **64** maps yield no strict refinement (2 old +62 new).

**Independent combinatorial cross-check (does not reuse the semigroup code):** The old partition has two 2-element blocks. A deterministic map h cannot distinguish the old equivalence classes if it sends the two members of **each** old block into a common sensor block (not necessarily the same target block). For one input block there are 2 choices of target sensor block and 2 choices for each of its two individual images, giving 2×2²=**8** valid maps. For the two input blocks there are 8²=**64** partition-preserving maps; every old generator also preserves the partition, so their compositions cannot refine it. The remaining 4⁴−64=**192** maps fail to preserve the partition and immediately split it. A separate local Python enumeration independently compared this closed-form block criterion to the executable closure implementation and obtained **64 vs 64** non-refining maps. This proof explains the 192/256 count without treating a passing unit test as a mathematical derivation.

Each map was examined by finite closure generation. An exhaustive test additionally verifies that adding actions never **coarsens** the old observational partition; another exhaustive test verifies that if every initial state has the same sensor output, no one additional state transformation discriminates anything.

The fraction 192/256=75% is **NOT** an empirical probability that new scientific technologies will work. Uniformly sampling arbitrary state maps is not a physically warranted probability distribution over real instruments; most functions may be impossible in actual laboratories. This illustrates the same reference-class issue as the earlier [64 graph census](mqr_54_chat42_04_graph_contact_census_and_reference_class.md).

## The research frontier actually advanced, and what it still misses

Relative to the earlier MQR42 [contact-stabilizer model](mqr_54_chat42_04_contact_stabilizer_conditional_proposition.md), this model distinguishes **newly available action grammar** from **new observation** and **new description**. It does **not** generate the new h from two unknown independent experimental languages: S, o, f and h are all supplied by one analyst in advance, and a four-state simulator cannot establish physical executability. Even the positive h demonstrates merely a *logical possibility of action-language expansion*, not actual invention of an apparatus or a new ontology.

The historical near neighbors must constrain originality claims: [Feest & Steinle (2012), *Scientific Concepts and Investigative Practice*](https://drive.google.com/file/d/1WJyJHhYFi3R27QNfNOu5Jr4pmsdq5Ua9/view), especially Feest's chapter on exploratory experiments and conceptual/theoretical co-revision, and [Clement (1988), *Learning via Model Construction and Criticism*](https://drive.google.com/file/d/1X_EeNfK7g5ablkwQweNpyU_Jhy0uIxTk/view). They already study important parts of the epistemic feedback loop: the current addition is a transparent **small finite counterexample and implementable distinction**.
