## III. Sethna et al. 1993: a disciplined donor for history and hysteresis
Owned original: [Sethna, Dahmen, Kartha, Krumhansl, Roberts & Shore, *Hysteresis and Hierarchies*, PRL 70 (1993), pp.3347–3350](https://drive.google.com/file/d/17ma_HtSdboFGJxVK8Dv-gd4Iohj8bb_D/view). Four printed pages, 268,706 bytes, mostly OCR-broken text; abstract, Fig.1 captions, passages describing athermal zero-temperature random-field Ising model and history/avalanche memory read; graphics/line-by-line proof not inspected. **NOT FULL VISUAL C3**.

Source describes zero-temperature disorder-driven first-order transitions with ascending/descending external field, avalanches and **return-point memory**. In this model an excursion that reverses and returns to a previous extremal field can return to a previously visited microscopic metastable state, with nested subloops/hierarchies. The paper expressly notes that such return-point behavior occurs in **some, not all** first-order transitions and that some hysteretic systems display drift. The label 'hysteresis' alone does not determine a unique compact sufficient-state variable or guarantee return-point memory.

**4.121 notebook:** Distinguish at least four statements:
1. current displayed output equal;
2. current coarse state variable equal;
3. future responses equal for a declared intervention family;
4. full microscopic state equal.
Neither (1)⇒(2) nor (2)⇒(3) holds without a state-sufficiency contract. The Sethna model demonstrates conditional (4)-like memory in a **specific** dynamics and field history; it is not a generic rule for UV–Vis pH/thermal cycles.

**Proposed falsifier design:** Two thermal/pH paths end at same measured A and T; compare a predeclared controlled perturbation, collecting multiwavelength spectra and auxiliary time-/composition-sensitive measurements. Differences can defeat an insufficient state description; absence of differences only supports sufficiency over the tested perturbation family. Do not claim that a thermal route actually produces return-point memory in methyl red; requires new physical data.
