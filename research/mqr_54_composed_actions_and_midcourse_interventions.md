# MQR 5.4 — 한 조작과 여러 단계 사이에 개입할 수 있을 때

2026-11-17 KST · [5.4 헌장](MQR_5_4_OPEN_HORIZON_CONSTITUTION.md) · [이전 DFS/BFS](mqr_54_josephson_dfs_bfs.md)

## 대응을 정한 뒤 열어 본 질문

기존 [조작 번역 연구](mqr_54_action_translation_and_joint_experiments.md)는 양쪽 조작 이름 사이의 전단사를 후보로 두었다. 이번에는 대응 하나를 명시한다. 왼쪽 실험실의 `apply`는 단일 상태 전이이고, 오른쪽의 `apply`는 순서가 고정된 `arm → commit`이다. 현재 실험은 주어진 대응 아래의 결과를 계산하며, 대응의 자동 발견은 후속 문제다.

물리 출력 `x`, 내부 래치 `h`, 래치를 복사한 판독 기록 `r`은 각각 0 또는 1이다. 처음에 세 비트는 0이다. 왼쪽은 시작 신호에서 그대로 기다리다가 완료 시 `x`를 뒤집고 `h`를 0으로 만든다. 오른쪽은 `arm`으로 `h=1`을 설정하고 `commit`에서 `x←x⊕h`를 수행한 뒤 `h=0`으로 돌린다. 독립 판독 `inspect`는 `h`를 `r`에 복사하고 `x`, `h`는 보존한다. 개입 `clear`는 `h=0`으로 설정하고 `x`, `r`은 보존한다. 단일 조작도 같은 두 시점에서 시작·완료한다고 둬 개입 시간을 맞춘다.

| 허용한 절차 | 처음 갈리는 기록 | 관측되는 것 |
|---|---|---|
| 완료된 조작 `apply`와 경계에서의 `inspect`, `clear` | 없음 | 8개 시작 상태 모두에서 한 번의 완결된 조작이 같은 완전 상태로 간다. 두 경계 조작도 동일하므로 유한 길이의 모든 후속 선택과 적응적 선택에서도 같다. |
| 시작·완료 시점만 맞춰 관측 | 없음 | `begin`이 내부 래치를 바꾸더라도 일반 출력과 판독 기록에는 아직 차이가 없다. |
| 중간 `inspect` | `begin → inspect` | `x`는 양쪽 0이고 래치 복사 기록이 왼쪽 0, 오른쪽 1이다. 이후 `x`는 양쪽 1이다. |
| 중간 `clear` 후 완료 관측 | `begin → clear → finish` | 중간에 래치를 읽을 필요 없이 최종 `x`가 왼쪽 1, 오른쪽 0으로 갈린다. |

경계 결과의 증명은 합성이다. 완결 전이 `F`와 합성 전이 `C∘A`가 모든 상태에서 같고 모든 경계 조작 역시 같은 함수를 쓰므로, 같은 관측 이력이 다음 조작을 고르는 조건에서는 두 이력이 계속 같아진다. 중간 개입 `I`는 `C∘I∘A`를 만든다. 이 사례에서 `I=clear`이면 `C∘I∘A`가 출력 비트를 유지하고, 단일 조작 쪽은 비트를 뒤집는다. 시작 시점과 끝을 더 자주 확인해도 경계 전이가 같다는 사실은 바뀌지 않는다.

[`compile_words`](../language/real/experiments/action_words_v54.py)는 원래 기계의 어떤 이름을 어떤 순서로 실행할지 명시하면 모든 상태에 대한 합성 행을 계산한다. 기존 최저 비용 탐색을 재사용했다. 같은 단위 비용에서 중간 관측의 최단 기록은 2단계, 중간 개입의 최단 기록은 3단계다. 예산 2에서 후자는 비용 한도 밖에 있고 그 증인 자체는 여전히 존재한다. Real-Lang Python 실험 전체 106개 통과. 비용은 모형의 단위 비용이며 초 단위 실험 시간이나 물리 측정 성능을 뜻하지 않는다. [테스트](../language/real/experiments/test_action_words_v54.py).

## 선행연구와 5.4의 질문

van Glabbeek–Goltz의 1989 학술대회 논문과 2001 확장판은 추상적으로 같은 동시 실행을 더 세밀한 조작으로 전개할 때 어떤 동등성이 보존되는지 다룬다. 중간 과정이 허용되면 기존 동등성이 깨질 수 있다는 관찰에는 분명한 선행연구가 있다. Herlihy–Wing의 선형화 가능성도 호출과 응답 사이에서 하나의 조작처럼 보이도록 할 수 있는 이력의 조건을 명시한다. 이 연구 예는 스케줄러 보존성이나 선형화 가능성을 새로 증명하지 않는다. 두 실험실이 같은 최종 결과를 기준으로 대응을 승인한 뒤, 어떤 공통 판독 또는 개입에 의해 승인 범위를 바꿀 수 있는지 접근 조건을 바꿔 확인한다. [1989 원문](https://cgi.cse.unsw.edu.au/~rvg/pub/refinement89.pdf) · [2001 확장판](https://doi.org/10.1007/s002360000041) · [Herlihy–Wing 원문](https://www.cs.columbia.edu/~wing/publications/HerlihyWing90.pdf).

다음에 판별력이 큰 경우는 중간 래치에 직접 접근하지 못하는 경우다. 상대에게 공통 이름 `clear`를 주지 않고, 결과 판독만 공유한 실험실이 시작 지연·부하·외부 신호 조합으로 같은 인과 구별을 만들 수 있는지 묻는다. 개입의 공통 대응 자체가 없으면 두 경로에서 무엇을 함께 비교할 수 있는지를 다시 설계해야 한다. 이것이 외계 과학의 질문에 더 직접적으로 닿는 부분이다.
