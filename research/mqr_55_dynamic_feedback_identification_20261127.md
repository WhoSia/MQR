## Model and results
State and intervention are Boolean, transition table time-invariant and deterministic, state fully and correctly observed, each independent trial reset to 0, both interventions feasible. There are 16 tables (F00,F01,F10,F11). Two concrete worlds reversible=(0,1,0,1), persistent=(0,1,1,1) agree at every prefix of every constant-policy word. They disagree on word (1,0). Thus repeating constant interventions cannot identify persistence; introducing an order-sensitive experiment can discriminate without a new sensor. This is an elementary finite-state distinction, not new automata theory or evidence of actual policy hysteresis.

The two-step completeness argument: suppose all one-step endpoints and all two-step endpoints agree from reset 0. If some first action leads to 1, both worlds reach 1 under it; the subsequent pair of actions reveals the transition row from 1, while first actions already establish the row from 0. All table entries then agree. If neither action reaches 1, both systems stay at 0 under every finite word. Hence all finite endpoints agree, and because every prefix is itself a finite word, all traces agree. Unreachable row disagreement is not identified by this experimental regime. This does not imply metaphysical equivalence or that a larger state space has a length-two bound.
