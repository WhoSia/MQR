## 1. Model-class failure versus durable observation

The earlier [native learner](mqr_54_chat43_05_alignment_blind_active_query_learner.md) considers six analyst-specified B-to-A state alignments. Its observation method rejects an impossible result before appending it to its own learning ledger. This correctly preserves the frozen candidate state but would lose scientific anomalies if no separate external evidence record existed.

The new sidecar model does two things separately: retain a typed, externally *claimed* observation including adverse controls and provenance; **never** silently alter the closed six-candidate class or promote a novel scientific concept from an exception. Active automata learning already uses model counterexamples, notably [AALpy (2022)](https://doi.org/10.1007/s11334-022-00449-3). This code does not claim a new algorithm.

## 2. A precisely off-model native word

Lab A begins with a low readout. In the frozen model, B:shift is an involution: applying it twice is the identity for **every** of the six hidden alignment permutations. Thus the A-native result of two successive B:shift actions must be low in the entire frozen class. A reported **high** is impossible **conditional on** the idealized fixed preparation, native operation semantics and reliable A readout.

An analyst-proposed rival replaces B's involution by a three-cycle and produces high after that double action under one fixed alignment. An A-only negative control remains low; a globally inverted sensor would instead fail this control. A proposed five-B-action follow-up also gives different native results under the two *stipulated* mechanisms, prospectively relative to the toy story, not a real instrument preregistration.

An unconstrained query-dependent sensor artifact is explicitly assigned the same output table as the three-cycle for all allowed queries. This construction is intentionally adversarial and not an empirically grounded failure mechanism. It demonstrates **native-output underdetermination**, not that the physical three-cycle and an actual sensor defect are equally likely.

## 3. Independent-report and control tests

An append-only trial record includes trial identity, stated evidence-lineage identity, the native action word, the observed symbol, a fixed A-only negative-control result, and external declarations concerning specimen identity, preparation preservation, reset and sensor calibration. False gate flags quarantine the report but do not destroy it. Duplicate trials and malformed records are rejected without changing the register. Control failures are retained but excluded from the current model assessment.

The classification distinguishes: no qualifying evidence; only one **declared** lineage; inconsistent native outputs across nominally qualifying runs; agreement with the sealed model; and repeated independent-*labeled* off-model outcome. The last has the status **HOLD_CONDITIONAL_FROZEN_CLASS_REFUTATION**, not scientific PASS: independent textual lineage IDs and Boolean receipt claims do not certify physically noncommon errors or true repeated world contact.

## 4. DFS stop and return to founding question

The actual scientific question is not merely which of six candidate dictionaries fits observations. It is whether a persistent, materially audited discrepancy makes the scientists revise the **conceptual question itself**: new preparation, modified action semantics, a changed observability relation, or a new explanatory target. The present prototype does not create these primitives; a human analyst proposed them.

An independent sensor or independently grounded contact route that could disagree with the proposed mechanism is needed before physical interpretation. The DFS branch has achieved its limited formal no-go and should **BACKTRACK** until such data exist. The next BFS probes historically documented concept plurality and rejected cross-disciplinary anomalies rather than continually enumerating state permutations.
