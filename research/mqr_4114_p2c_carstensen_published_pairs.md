## Source's explicit rival against its own estimator

The author warns that in the linear measurement-method model, the pair-average can be **correlated with the residual**, compromising naïve regression interpretation. The paper shows a covariance-zero condition tying slope and **ratio of method-specific residual variances**. Crucially, there is **one measurement per item and method**, no method-specific replicate variance in this data; the author states that the individual error variances (and variance ratio for a general Deming regression) are not identifiable without assumed values or replicates. Source additionally excludes heteroscedasticity, warns that scale changes affect comparison interpretation, and does not measure independent external physical calibration ancestry.

**This directly prevents a false MQR conclusion:** The fitted affine mapping and directional prediction intervals are identifiable *within their modeling assumptions*, but absolute measurand value, true calibration, method-specific error allocation, cross-device common drift and safe substitution cannot be certified merely from them. Table II illustrates **shared-source transformations**, while Table I illustrates physically **different biological matrices**. Source-published observations and independently certified source-original raw device traces are not the same evidence class.

## Formal model gauge and target of discovery

For Carstensen's general affine reference model `y_mi = α_m + β_m θ_i + e_mi`, an arbitrary shift `c` of the unobserved latent origin, accompanied by `θ_i' = θ_i+c` and `α_m' = α_m−β_m c`, leaves each observed measurement exactly unchanged. This is a straightforward classical algebraic **reference-origin gauge freedom**, formalized in [Lean](../experiments/mqr-4.114/lean/MQR4114PublishedMethodGauge.lean) as an illustration, not a newly discovered theorem. Even an extra instrument sharing the same unknown reference origin cannot fix it; a genuinely independent physical reference can break the equivalence only after demonstrating its real identity, accuracy and ancestry.

The MQR-4.114 **substantive** question now becomes: *which independently source-authenticated perturbation/cross-device reference patterns exclude correlated-calibration and distinct-measurand rival models, when a numerical conversion successfully fits already published source pairs?* Existing model-comparison literature already knows the regression and error-in-variables problem; MQR's contribution, if any, requires external physical falsification or a uniquely useful, independently validated typed reference-authority mechanism. Graph-arrow concentration (P1) does not automatically confer such authority.
