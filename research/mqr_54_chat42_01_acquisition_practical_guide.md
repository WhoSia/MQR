**목표:** '원시 데이터'라는 말만으로 실험을 시작하지 않는다. (a) 파일이 실제 공개됐는가, (b) 데이터가 그래프 가공본인지 장비 원시 열인지, (c) 동일 실행의 *paired* 샘플인지, (d) 어떤 조건에서 반복됐는지, (e) 공개 해시/라이선스가 있는지 확인한다. 저작물 DOI는 실험 원시파일의 DOI와 다르다. 이 목록은 실제 공개 랜딩/파일 배포 링크를 웹으로 확인한 결과이나, 이 실행 환경의 공개 파일 이진 다운로드가 성공하지 않아 **내용에 대한 수치 재분석이나 ZIP SHA-256 검증을 수행했다고 주장하지 않는다**.

## P1 — 공개 데이터 대체 연구는 가능하지만 **정확한 파일은 요청해야 함**

1. **Behr et al. (2015), *Metrologia* 52:528–537, DOI [10.1088/0026-1394/52/4/528](https://doi.org/10.1088/0026-1394/52/4/528)**: ask PTB to share **JAWS–ac-QVM figure-level raw repeated observations**, instrument/run metadata and common reference/clock/cable records, especially 1V RMS frequency sweep 30Hz–2kHz and Fig. 7's 14 readings/3 days at **250Hz**. Avoid falsely saying the 2015 article performed a **paired thermal standard** validation. Article corresponding author address **`ralf.behr@ptb.de`** appears in the journal publication. Accessible paper is already held on Drive.
2. **Burroughs et al. (2013), *IEEE TIM* DOI [10.1109/TIM.2013.2250192](https://doi.org/10.1109/TIM.2013.2250192)**: NIST [official publication page](https://www.nist.gov/publications/method-ensuring-accurate-ac-waveforms-programmable-josephson-voltage-standards) has **Local Download** of a *paper*, not original multi-sample transition windows. Ask NIST publication team/authors for digitized transitions, sampling rate, ADC bandwidth, bias configurations and baseline reference if sharable. Contact the official NIST publication page's questions channel, not any invented separate dataset DOI.
3. **Optical AB/BA sequence with blocked/open references and common time/identical setup**: this is **a proposed experiment**, not a specific extant dataset whose author or DOI we know. Durham/Zenodo provide real optical data for a different pilot; to make the requested causal order-invariance claim, **collect new paired AB/BA records** with order randomization, blocked reference, open reference, simultaneous/adjacent timing, angle and detector controls.
4. **Same hyperspectral device input-optics before/after intervention**: also **a prospective paired experiment**, not a demonstrably missing public accession. [Talone et al. (2016)](https://doi.org/10.1364/AO.55.003966) offers published stray-light treatment but not the exact claimed intervention raw pair. Before claiming it exists, request from corresponding authors or a target metrology lab and specify same spectrometer serial number, same optics reference, instrument/dark spectra, before/after timestamps and reference source.

## Download and acceptance on Windows

Use a browser first. PTB: site > *Download File* > ZIP. NIST: dataset page > each resource Download (6 files). Zenodo: record > Files > Download; .7z unpack with modern Windows or 7-Zip. Durham: Download > original ZIP. If downloaded, place **unaltered** archive in Research OS `00_INTAKE` with its original name; **never edit a raw source file just to add labels**. On Windows PowerShell:

```powershell
Get-FileHash -Algorithm SHA256 -Path 'C:\\path\\PTB_measured_data.zip'
Get-FileHash -Algorithm MD5 -Path 'C:\\path\\QuantumPower_data.7z'
```

For PTB, compare to official SHA; for Zenodo 2023 and Durham compare to the publisher's MD5. For NIST CSV read **README before interpreting units**, preserve raw files and record URLs, timestamps, version, file size, hash. Before calculating physical results, determine raw-vs-processed, reference and pairing keys. Also note that `Get-FileHash` hashes the downloaded *archive*, not separately every decompressed member. The user should not need to rename these files manually if placed in 00; curator can canonicalize and annotate the source role.

## Why this changes MQR's research direction

The decisive frontier is **experimental identity and transport**, not downloading *any* related CSV. A dataset can be valid and well-described while still not identifying the cross-method/systematic error intended by MQR. In one method the comparator is part of the voltage synthesis, in another an instrument is calibrated before measuring the source: the error terms and common-mode assumptions differ. Similarly, a polarizer's angle sweep is not a source-order reversal. Reproducible negative result: if local experimental responses can be permuted without changing any observable record, **there is no unique cross-science preparation mapping**, even if the filenames agree.

The original 18-target list is historical; the current strict list becomes **17** on the newly acquired 1968 volume. Classify **four active experimental blockers** separately from **thirteen remaining precise archival-identity/version targets**; two of those thirteen are partly satisfied by equivalent text witnesses (Saxon 1945 memorandum in 1968 volume, Maxwell 1890 collected vol. I facsimile). They cannot be counted as 'raw data still missing'. [Full bookkeeping](MQR_LIVE_MISSING_SOURCES_REGISTRY.md).
