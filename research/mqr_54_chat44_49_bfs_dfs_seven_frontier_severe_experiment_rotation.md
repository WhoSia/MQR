# MQR 5.4 · MQR 44 · R49 — BFS/DFS rotation across the seven founding frontiers: next severe experiments

**2026-11-23 KST · research-director's adversarial synthesis**. MQR 5.4 OPEN. This is a disciplined allocation of research attention and a falsification table, not a new scientific law, version promotion or promise of asynchronous work.

## 1. How much has the local question-invention experiment truly established?
Single finite four-world environment, progressively altered ONE premise at a time:
- **R44-0:** A and B are measured separately on disjoint specimens → equal marginals under two opposite joint worlds; `P(A XOR B)` not identified.
- **R44-1:** same-specimen, valid *non-disturbing* joint readout → correlation identified; the observable-function linear span grows rank 3→4 (normalization included).
- **R44-2:** full joint data → still cannot decide fork U→(A,B) from chain U→A→B; targeted `do(A)` theoretically separates them.
- **R46:** record linkage correct only with probability p → observed association is product `pr`; unless p is separately calibrated, association is not identified. P=0 erases information regardless of infinite sample.
- **R48:** assays destroy the other variable on first read → even perfect matching IDs and unlimited sequential paired records cannot reveal original association; operation order and state change matter.

This is an **incremental epistemic impossibility ladder** with three independent bottlenecks: no joint data, unreliable data alignment, and physically perturbative measurement. It is mathematically elementary but a powerful diagnostic because different interventions solve different bottlenecks. The exercise *does not* prove the historic birth of a previously inconceivable concept, nor does it derive a new theorem beyond standard statistics/causality.

## 3. What would defeat the fashionable but weak 'MQR master theory'?
- If all purportedly new experiment questions can be matched to prior actor records with unchanged physical feasibility, novelty was only historical relabeling.
- If a researcher can simulate all 'new' capabilities from archived signals by free postprocessing under unchanged target, Blackwell implies no genuine added optimal value for that task.
- If physical measurement does not perturb the needed state, the R48 destructive case cannot apply.
- If data pairing is known perfect, R46's uncertainty-in-linkage confounding disappears.
- If the only philosophical value is unifying **already known** Feest, Rheinberger, Wigner, Mitchell, Chang, causal inference and Blackwell, treat MQR as a source-critical integrative research programme, not a fundamentally new ontology.

## 4. Working title and concrete scholarly contribution threshold
*When Questions Become Measurable: Three Bottlenecks of Scientific Integration* is a potential methodological note rather than a completed paper. To earn novelty beyond an elegant classroom exercise it needs:
  (1) a historically real independent multi-technology case;
  (2) an independently reproduced empirical benefit or failure of sample linkage;
  (3) a dated method transition whose effect was **not** completely anticipated by prevailing model assumptions;
  (4) a severe existing-method baseline (Blackwell/Le Cam, causal identification, Campbell–Fiske, Mitchell and Feest);
  (5) an actual negative control where paired data adds nothing or destructive assay order is irrelevant.

No new physical experiments or instrument instructions are supplied, no user access to Feest paywalled book is assumed, and no new missing PDF is invented. **Keep MQR 5.4 OPEN.**
