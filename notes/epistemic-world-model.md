# Epistemic World Model / Origin-Return Note — live through MQR-3.155

This is intentionally a lightweight living note, not a mirror of the Notion genealogy.

## Why this file exists

AI, causal abstraction, UV–Vis, ozone and OPERA are application courts. They are not MQR's founding subject.

MQR's older questions remain primary:

- can A and B both be real without reality becoming arbitrary;
- can a higher law be more than a lookup table over known history;
- can several incompatible methods increase rather than destroy realist warrant;
- can a scientific language remain corrigible when its own ontology determines what can count as evidence;
- can a law or ontology earn authority by risky exclusions over possible worlds rather than by compression alone.

The intended development cycle is:

`ORIGIN QUESTION -> FORMAL VULNERABILITY -> WORLD CONTACT -> ORIGIN RETURN`.

Formalism is an instrument of the philosophy, not its replacement.

## Quotient-level corrigibility

A representation-induced equivalence is a defeasible scientific commitment. A world-forced split does not automatically create a natural kind, and a retained split must survive recombination pressure.

- `PREDICTIVE EQUIVALENCE != EPISTEMIC EQUIVALENCE`
- `QUOTIENT BREAK != KIND BIRTH`
- `STABLE RESIDUAL != NATURAL KIND`
- `SPLIT SUCCESS != SPLIT PERSISTENCE WARRANT`

## Composition discipline

Two individually warranted revisions need not compose epistemically.

- `PAIRWISE WARRANT != JOINT WARRANT`
- `FORMAL COMPOSABILITY != EPISTEMIC COMPOSABILITY`
- `SAME TERMINAL PARTITION != SAME EVIDENTIAL HISTORY`
- `REFINEMENT COMPLETENESS != EPISTEMIC PATH INDEPENDENCE`
- `FORMAL DIAMOND CLOSURE != AUTHORITY DIAMOND CLOSURE`
- `PATH-DEPENDENT EVIDENCE != PATH-DEPENDENT REALITY`

A Common-Endpoint Replay can test whether apparent path dependence survives restoration of a common challenge family.

## MQR-3.155 — non-isomorphic co-realism

Two scientific ontologies need not share primitive objects, variables, partitions, or vocabulary to earn the same scoped realist authority.

MQR-3.155 introduces **Cross-Abstraction Authority Bisimulation (CAAB)**: two ontologies may be authority-equivalent over a declared scope and challenge family when they support materially corresponding world-facing consequences, transport each other's load-bearing defeat conditions, and preserve comparable routes for future correction.

This is not definitional equivalence, Morita equivalence, categorical equivalence, literal isomorphism, or semantic identity.

- `EMPIRICAL EQUIVALENCE@Q != GLOBAL ONTOLOGICAL IDENTITY`
- `TRANSLATABILITY INTO A != NEUTRAL COMPARABILITY`
- `SAME REALITY ACCESS DOES NOT REQUIRE SAME ONTOLOGY`
- `DIFFERENT ONTOLOGY DOES NOT REQUIRE DIFFERENT REALITY`
- `CURRENTLY INDISTINGUISHABLE != FOREVER EQUIVALENT`

The authority relation is query-family-relative and defeasible by fresh world contact.

## Feyerabend return

Feyerabend's useful pressure is not 'difference is automatically good'. It is that rival frameworks can manufacture potential falsifiers that a dominant theory and its observation language cannot generate from within.

MQR retains that anti-monopoly principle while adding a realist restraint:

`METHOD PLURALISM != ONTOLOGICAL ANARCHISM`

and

`REALIST DISCIPLINE != ONE-METHOD SOVEREIGNTY`.

Plurality earns authority only when it creates nonredundant reachable defeat.

## Higher-law return

A common vocabulary is not required for a common world-side law. A higher-law candidate earns authority only when it supplies non-vacuous modal excess across domains:

`cross-domain constraint + novel prediction + defeat exposure + non-vacuity`.

A lookup table that merely reproduces known history fails this test even if it fits perfectly.

## Formalism Service Criterion

A formal object in MQR should survive only when it does at least one of the following:

1. exposes a hidden circularity;
2. preserves a rival or defeat route that prose would blur;
3. separates claims that philosophy tends to conflate;
4. enables a historical or executable stress test capable of changing the philosophical verdict.

`FORMAL PRECISION WITHOUT NEW DEFEAT GEOMETRY = NOTATION DEBT`.

This criterion is not anti-mathematical. It is the reason mathematics belongs in MQR at all.

## Origin Fidelity Gate

After a long technical branch, MQR should ask:

- Which founding philosophical question did the branch sharpen?
- What philosophical proposition changed because of it?
- Which rival philosophy became stronger or weaker?
- Did a new equation expose a new possibility of defeat, or merely rename bookkeeping?
- Can the result speak about science outside the engineering example that generated it?

A branch that cannot answer these is `TECHNICALLY PRODUCTIVE / PHILOSOPHICALLY SATURATED` and should compress or terminate.
