**Status:** OPEN / P0 RESEARCH CONSTITUTION, not an empirical-success claim. **Date:** 2026-10-08. **Parent:** MQR-4.90 bounded source-reproduction court. **Character:** empirical methods + formal science; not an abstract governance audit. **Primary risk:** rediscovering fixed-background AUC and general-purpose provenance/transport results.

## Lock the exact explanandum

When two reported performance numbers appear to evaluate "the same model", what **observable additional data and admissible transformations** permit their comparison as estimators of a common target performance functional? If none, what *witness* demonstrates the nonidentification and what missing source contract(s) would repair it?

The primary estimand for a held-fixed original fitted score function `f` and a target sampling protocol is

`AUC(f; P_target_pos, Q_target_neg)=E[1(f(X+) > f(X-)) + 1/2 1(f(X+)=f(X-))]`.

A same-functional contrast may alter **exactly one declared axis** at a time: the fitted predictor, positive sample, negative reference distribution, spatiotemporal domain, model-selection protocol, or replicate root. A *fold-to-full* comparison on a fixed external target is a matched-target model comparison, not automatically an estimate of spatial CV optimism. Cross-validation optimism additionally requires fitting/selection and validation procedure definitions and appropriate joint sampling uncertainty.

## P0 scientific axioms (to be challenged, not assumed as original theorems)

1. **Source-first computation.** Reported point estimates are not raw independent effects. Use original source arrays, scores, geographic grids, fitted model components, software version and source SHA/MD5 receipts when allowed.
2. **Observed vs inferred vs conditional.** Source-computed scores, analytically proved equalities, simulated sensitivity, and truly bounded unidentifiability occupy separate namespaces. Never substitute numerical `δ` for measured TV distance, or a constructed grid's `Q_all` for Maxent's original CV background.
3. **No pseudo replication.** Matsui ten targets arise from one paper / three species; 12 CV fold scores correlated within source. Wang Amazon has Wadoux lineage. Koldasbayeva 108 supplementary rows summarize repeated models, not 108 studies.
4. **Novelty rivalry mandatory.** Phillips 2009, VanDerWal 2009, Baker 2024, Serov 2026, Bareinboim & Pearl 2013, Lee & Bareinboim 2020, Calautti et al. 2024, and existing fixed-evaluation / transportability / minimal-provenance results are explicit baselines. A fixed Q counterfactual alone, TV bound alone, or two-world summary identification argument alone are **not new methods**.
5. **Bounded algorithmic claim.** A source-repair witness list is NOT provably cheapest, minimum cardinality, or complete absent a precise finite repair operator catalog, accessibility restrictions, equivalence semantics, cost model and proof.
6. **Three-language soundness.** Rust independently computes reference and model comparisons; Lean proves named restricted propositions, and Prolog tests source genealogy/nonpromotion and reportable failures. Agreement of three code paths cannot prove that the science's assumptions hold.

## The experimental design

**P1 — Source replay; empirical admission gate.** Starting from MQR-4.90 P9, pin Maxent Java 3.4.4 by Git blob, both Matsui source ZIP hashes. Replay one published final target .asc with model .lambdas+original 8 climate rasters; compare pixel geometry, transform and original numerical scores. Only after exact compatibility within predeclared threshold, project four genuine cross-validation fold models onto the identical target raster. If replay fails, produce a typed failure certificate, no false AUC.

**P2 — Same-target AUC and counterfactual factorization.** Align external positive/unrecorded-negative cells via original geographic raster geometry and missing-value mask. Recompute four fold-versus-final AUCs with held-fixed P+ and Q−, label all transformations. Reevaluate the five source model identities if and only if actual evidence supports reconstruction. Distinguish model-specific contrast from reference-only mixture effect and from CV optimism.

**P3 — Independence and precision.** Build sample-root dependency DAGs; report spatial-block or spatial-cluster uncertainty only with spatial coordinates/units available. AUC point estimates without defensible sampling model get no fabricated SE and no inverse-variance pooling.

**P4 — Rival stress test.** Reconstruct at least one independent paper with genuinely comparable score metric/negative-reference/fitted model target. Independently scrutinize Wang 2023 and Serov 2026 as candidates, but Wang's absolute RMSE discrepancies cannot be blindly pooled with AUC; Serov's selection on test AUC may bias inference. Compare to established fixed-background model evaluation.

**P5 — Scientific repair compiler.** Typed `EvaluationContract` tracks model hash, train policy, target P+, target Q−, background sampling, label-dependent selection, dependence roots, metric, estimate uncertainty and underlying record hashes. Output one of (A) source-recomputed comparable, (B) conditionally bounded, (C) finitely nonidentified with explicit worlds, (D) unsupported evidence. Candidate minimal missing-input witness set has formal limitations; seek actual restricted completeness or empirical value beyond baselines.

## Hard success and stop rules

- First public demonstration must show **actual recomputed** raw target predictions or **verified failure** from pinned original artifacts; planning/routing documents don't pass.
- Paper A requires source-replay results, original authors' methodology faithfully represented, at least two distinct study lineages or explicit bounded case-study status, and a transparent rivalry/novelty section.
- Paper B requires baseline comparison and either a formally restricted completeness theorem or demonstrated practical superiority over a conventional manual source audit. Unproven title-level novelty is prohibited.
- No cross-paper signed pooled CV optimism until independent, variance-bearing, same-estimand effects and dependence handling exist.
- Stage may close as NEGATIVE/SCOPE-BOUNDED if source replay or bridge unavailable; do not optimize for a preordained positive finding.
